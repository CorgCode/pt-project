# Обычная страница модели на основе кейса Noomo

Открыть `/model/`. Главная не менялась.

Вместо придуманной 3D-сцены перенесён шаблон https://noomoagency.com/work/noomo-labs-the-jellyfish: `.case-hero`, заголовок, сетка `.info-block`, `.more-info / .wrapper-more`, исходный фон, стили `entry.9bea82f5.css` и `nextCase.955edb1e.css`. В `reference/case-original.css` скопированы inline-стили страницы; изменены только локальные пути шрифтов. Содержание и метаданные заменены сведениями нашего проекта, чужие награды, клиенты, формы и ссылки на контакт удалены.

Масштабирование обложки при прокрутке (`scale:.82`, `center bottom` → `bottom top`) перенесено из оригинального `caseHero` в `nextCase.vue.548e9dbe.js`. Ролик с медузой отключён; его исходный файл сохранён только в архиве reference. Вместо него показана схема нашей модели. Собственный `scene.js` сохранён в репозитории, но больше не загружается.

Оригинальный NeueMachina содержит кириллицу и используется для заголовков. NeueHaasDisplayRoman её не содержит; русский основной текст использует Onest с главной. Новая палитра не придумывалась: цвета и типографическая шкала взяты из исходных стилей кейса. GSAP и ScrollTrigger — из установленного пакета 3.14.2.

Схема MLP загружена из официальной документации scikit-learn; рядом указаны ссылка и пояснение, что это общая иллюстрация, а не точная топология наших голов. TF-IDF и Ridge сверены с документацией scikit-learn. Архитектура и результаты нашего проекта — из README модели и таблицы репозитория, а не из стороннего проекта.

`reference/source-manifest.json` содержит источники и SHA-256 оригинальных файлов. Исходные стили и шрифты не объявляются нашей разработкой или открытой лицензией; основание переноса — ранее сообщённое пользователем разрешение Noomo на адаптацию. Происхождение основной сцены также описано в корневом README.

`node tools/check-model.cjs` проверяет перенесённую структуру, контрольные суммы стилей, локальные аудио/шрифты/иллюстрации, обработку блокировки autoplay и переключение музыки, отсутствие собственного WebGL и чужих заявлений о клиентах. Проверка не заменяет визуальный просмотр в браузере. Computer Use в этой сессии не имеет разрешения на управление Chrome.


Добавлены шестнадцать иллюстраций: сборка профиля, сетевые признаки, состав вектора, адаптер, этапы обучения, общий балл с 95% интервалами, три тестовых дня и четыре отдельные метрики, принцип сравнения профилей и цикл обучения. Для каждой есть мобильный SVG. Числа берутся из `scoreboard/README.md`; контрольная сумма и исходные значения сохранены в `assets/evidence.json`. Сборка: `python tools/build-model-figures.py` (требуется matplotlib). PNG служат превью, сайт загружает SVG.

Музыка — `/audio/BG5.mp3`, тот же локальный трек, что на главной. Громкость 12%, зацикливание, кнопка в шапке. Попытка включения при загрузке; если браузер блокирует autoplay, повтор при первом действии пользователя. При каждом открытии музыка включена по умолчанию; кнопка позволяет отключить её до перезагрузки. Автоматический запуск без жеста зависит от браузера.


Обновление case-4: служебная боковая колонка убрана, область страницы расширена до 1180px, чтение — до 860px, схемы — до 1040px. Фон слегка осветлён без смены палитры. Заголовки появляются по словам из нижней маски, абзацы и схемы имеют отдельные плавные появления. Анимации выполняются один раз, не меняют позицию прокрутки; `prefers-reduced-motion` полностью отключает движения. Смысл заголовков сохраняется через aria-label. Новые схемы — концептуальные иллюстрации без вымышленных измерений.


Обновление case-5: 11 разделов, 16 иллюстраций. Добавлены подробный сценарий оператора, разбор пяти смысловых ветвей кодировщика, условная карта сетевых связей, принцип переноса контактов, аналитическая функция веса наблюдений, пояснение пяти метрик и рейтинг всех 17 методов. `assets/evidence.json` содержит исходные баллы рейтинга; они программно читаются из общей таблицы. Карта сети и схемы переноса явно обозначены как условные. Кривая полураспада — расчёт параметра, не измерение качества. Точные размеры MLP-голов многодневной модели не выдумываются: в доступной карточке они не опубликованы.
