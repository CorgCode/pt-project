# Страница модели

Открыть `/model/`. Главная и лаборатория не меняются.

Preview: atmospheric; последовательный разбор модели в девяти главах; amethyst-studio; Onest / Oswald. Центральная стеклянная схема сопровождает текст и меняет устройство при прокрутке. На телефоне она находится над текстом. Страницу можно читать без WebGL; обязательных переключателей или скрытых за вкладками глав нет.

`model.css` содержит палитру и шрифтовые токены. `model.js` управляет главами, появлением текста, выбором блока и доступным резервным режимом. `scene.js` содержит самостоятельную Three.js-сцену: скруглённые стеклянные поверхности, корпус с вырезом, потоки данных, историю, три части профиля и график оценок. Используется существующее HDR-окружение проекта. Схемы иллюстрируют смысл блоков, не заявляют точную нейронную топологию.

Описание сверено с `scoreboard/submissions/multiday_codebook/README.md`, `multiday_codebook_plus/README.md` и `scoreboard/README.md`. Дата таблицы указана рядом с результатами. Нет заявлений о точности обнаружения атак или подтверждённых ролях устройств.

`node tools/check-model.cjs` проверяет настоящую геометрию Three.js, смену глав, выбор 896/64/64, вращение, сброс и размеры 320/375/414/768/1440. Renderer в проверке заменён заглушкой: материалы, свет и композиция в реальном GPU-браузере пока не подтверждены. Computer Use сообщает об отсутствии разрешения на управление Chrome.
