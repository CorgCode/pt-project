# Лаборатория

Открыть `/lab/`. Обычная самостоятельная страница в стиле утверждённой `/model/`: исходный фон Noomo, NeueMachina + Onest, приглушённые светлые поверхности, GSAP-появления текста и блоков, та же музыка BG5 с кнопкой отключения. Источники шрифтов и оригинальных стилей описаны в `../model/README.md`. Главная сцена не меняется; старые `pt-page*.js` и Three.js здесь не подключены.

## Что работает

- Небольшой сгенерированный пример сетевых записей по умолчанию; дополнительные 24 и 300 синтетических профилей из `product-data.js`.
- CSV до 3 МБ: сетевые записи (10 000 строк, 500 хостов) либо готовые векторы (500 хостов, 1024 координаты). Файл остаётся в браузере; запросов на сервер для анализа нет.
- Поиск пяти соседей по косинусному сходству, выбор на карте/в списке/на схеме соседства, отдельный выбор пары для сравнения.
- Три живых графика Chart.js: карта, сходство соседей, значения признаков выбранной пары. Карта строится приближённым PCA по L2-нормированным векторам; её двумерные расстояния не заменяют полное сходство.
- Детерминированная spherical k-means: 2–6 запрошенных групп, ограничение размером набора, инициализация удалёнными профилями, 20 итераций. При совпадающих профилях непустых групп может оказаться меньше. Меток ролей нет.
- Схема ближайшего окружения с клавиатурным выбором узлов. Линии — сходство, а не сетевые связи. Координаты схемы условные.
- Загрузка с проверкой ошибок; при невалидном CSV последний корректный набор сохраняется. Новый выбор набора отменяет ожидающую загрузку.

`core.js` повторно использует CSV-парсер и расчёт проекции из старого `pt-page-lab.js`, добавляет проверку последовательности координат, переполнения и группировку. Сетевые записи переводятся в 20 простых признаков: направления и объёмы, число контактов, хешированные сервисы; log1p и масштабирование по набору. Близкие признаки пары показываются без нулей у обоих устройств. Это сравнение простых признаков, не интерпретация нейросети.

Лаборатория не запускает и не обучает `multiday_codebook_plus`, не обнаруживает атаки и не отслеживает изменения групп по времени. Готовые векторы сравниваются без предположений об их происхождении. Семантика отдельных координат embedding неизвестна.

## Проверки

`node tools/check-lab.cjs`: настоящие расчёты CSV, сходства и групп, выбор в DOM, обновление трёх конфигураций графиков, два формата импорта, 1024 координаты, ошибки и сохранение последнего набора, безопасное отображение имён, смена схемы на мобильную.

`node tools/render-lab-charts.cjs`: рендер действительных конфигураций Chart.js в CPU PNG, `/private/tmp/pt-ui-qa/lab-*.png`. Это проверка графиков, не снимок страницы в браузере. Полная браузерная проверка ограничена разрешениями Computer Use.

`npm test` включает проверки лаборатории и главной сцены. При отключённом движении в ОС появления и анимации графиков выключены.
