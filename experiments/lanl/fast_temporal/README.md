# Быстрый временной графовый энкодер v5/v6

Исследовательский эксперимент для LANL day02, связанный с #60. [Сохранённые результаты](../../../results/fast_temporal_day02/README.md): v6 — 47.57 на историческом test и 46.49 на позднем окне против 45.33 и 44.10 у исходного гибрида. Все числа — оценки на одном дне.

v5 учится узнавать один хост в двух половинах train. Входы: TF-IDF/SVD собеседников и сервисов, сочетания «собеседник + сервис», направленные сообщения по графу на один и два шага, активность. Энкодер 512→256→128 обучается с InfoNCE и сохранением поведенческого сходства. Его выход дополняет исходный гибрид.

v6 проверяет ограниченные веса блоков для каждого хоста и PCA-сжатие. В опубликованном эксперименте победило **PCA 825→384 без адаптивных весов**. Выбор сделан на validation; новое позднее окно заранее зафиксировано и не участвует в подборе.

## Повторить

Нужны подготовленные `processed/` и `reference/` исходного day02 ([инструкция](../README.md)). Рабочая папка должна быть пустой. Скрипт готовит только быстрые признаки, без повторного обучения DeepWalk/node2vec.

```bash
pip install -r experiments/lanl/fast_temporal/requirements.txt
python -m experiments.lanl.fast_temporal.run \
  --dataset /path/to/lanl \
  --workdir runs/fast_temporal_reproduction
```

Добавить проверку на новом окне:

```bash
python -m experiments.lanl.fast_temporal.run \
  --dataset /path/to/lanl \
  --workdir runs/fast_temporal_with_holdout \
  --with-holdout --raw /path/to/netflow_day-02.bz2
```

Train 11:00–12:00, validation 12:00–12:30, исторический test 12:30–13:00, поздний holdout 15:00–15:30. Порог активности — 300; когорта определяется только train. Сырые потоки и веса не включены в git. Новая проверка требует чтения всего архива и на исходной машине заняла около 16 минут; сами нейросетевые эпохи занимали секунды. Сжатие уже готовых векторов 6,453 хостов заняло 1.23 секунды, без извлечения признаков.

## Воспроизводимость и ограничения

`templates/` содержит скрипты выполненного исследования. Launcher переносит их в рабочую папку и задаёт пути через окружение. Каталог `hybrid_v4` используется как модуль вспомогательных функций; полный поиск v4 запускать не требуется.

v6 и новая оценка воспроизводят зафиксированный выигравший рецепт v5 (checkpoint 20, кандидат 07). Если при повторе v5 выберет другой рецепт, запуск остановится перед v6, сохранив результаты: применять адаптер с фиксированным порядком блоков к другой модели нельзя.

Проверенный стек: Python 3.12.2, numpy 1.26.4, pandas 2.3.3, scipy 1.13.1, scikit-learn 1.4.2, torch 2.5.1. Другие версии могут менять выбор кандидата и числа. Исторический test уже был просмотрен в предыдущих исследованиях; позднее окно — дополнительная проверка того же дня, а не доказательство переноса на другие дни.

Команды для итогового адаптера после обучения:

```bash
PT_REPO_ROOT="$PWD" PT_RUN_ROOT="$PWD/runs/fast_temporal_reproduction" \
  python runs/fast_temporal_reproduction/hybrid_v6_fast/infer.py \
  --input runs/fast_temporal_reproduction/hybrid_v5/candidates/v5_candidate_07/embeddings.csv \
  --output runs/fast_temporal_reproduction/predictions.csv
```
