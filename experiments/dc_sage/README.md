# DC-SAGE — обученный эксперимент

## Кратко

Направленная графовая нейросеть строит вектор из собственного профиля хоста и
профилей его соседей. Обучается узнавать тот же хост в двух половинах train
и предсказывать связи между ними. Спецификация: [Instruction.md](Instruction.md).

Результаты и сравнения сохраняются в `results/dc_sage_day02/`.
Веса, подготовленные данные и векторы находятся локально в `runs/dc_sage/`.

## Архитектура

Вход — TF-IDF/SVD-64 сервисов с ролями и 31 поведенческий признак.
Два направленных слоя GraphSAGE, 128 скрытых координат, top-64 соседей
с весами `log1p(count) × IDF соседа`. Остаточные связи, LayerNorm,
отдельный MLP собственного профиля и нулевая инициализация выхода графовой ветви.
Основной выход — 64 координаты; отдельно проверяется вариант 32.
Сохраняются составляющие вектора `own` и `graph` для объяснений сходства.

## Данные

LANL day02. Текущие общие окна проекта: train `[126000,129600)`, validation
`[129600,131400)`, test `[131400,135000)` — 60/30/60 минут.
В отличие от исторического примера инструкции test сейчас длится час.
Когорта и все оцениваемые хосты берутся из `scoreboard/data/`, без изменения порогов.
Дни 03–04 локально отсутствуют; общего балла по трём дням у этого прогона нет.

Граф направлен по `src,dst`; признаки используют протокол, оба порта, время,
длительность, байты и пакеты обоих направлений. Обезличенные порты остаются
категориями, число из них не извлекается. Токены в менее чем двух train-хостах
отбрасываются. Равные порты нейтральны, как в коде спецификации.

Из train выделены S1/S2 по 30 минут с удалением потоков, пересекающих границы.
Все словари, IDF, SVD и нормировки обучены на полном train и заморожены.
Признаки конкретного среза и его рёбра используют только потоки этого среза.
Узлы вне когорты участвуют как соседи, идентификатор узла не является признаком.
Соответствие индексов поддерживается внутри графа; при новом окне словарь может
расширяться, перестановка индексов проверена тестом на эквивариантность.

## Обучение и подбор

PyTorch, CPU, 4 потока. InfoNCE с температурой 0.1, маской ложных негативов
при косинусе сервисного профиля >0.95. Асимметричный декодер связей с отдельным
признаком популярности получателя. 50% позитивов — новые связи S2;
5 настоящих отрицательных примеров на позитив, без self-связей и рёбер S2.

AdamW, lr=0.001, wd=0.0001, cosine schedule, gradient clip=1,
dropout рёбер 0.2 и признаков 0.1. Один полнографный шаг за эпоху;
все допустимые контрастные хосты проходят батчи по 512 за этот шаг.
Это full-batch оптимизация с 50 обновлениями, а не 50 проходов mini-batch SGD.

До test проверены веса потери связей 0.1/0.3/1.0 на seed0. По штатному
validation score выбран 1.0. Остановка выбирается между эпохами 25 и 50
только по validation. Затем 9 вариантов × 5 сидов 0–4: полный метод,
skip-only, без направления, без IDF, без InfoNCE, без link loss,
без маски негативов, один слой и 32 координаты.
Экспортный seed выбирается по validation до оценки test.

## Ограничения

Нейросетевая архитектура не гарантирует преимущество над простым агрегатом или гибридом.
Нулевая инициализация графовой ветви обеспечивает старт с MLP, но не математическую
нижнюю границу качества после совместного обучения. Все сравнения следует смотреть
в отчёте, включая результаты без графа и разброс пяти сидов.

Из четырёх стандартных задач используются косвенные эталоны, меток настоящих ролей нет.
Текущий test дня 02 уже использовался проектом раньше; новым независимым днём он не является.
Нельзя сопоставлять полученный day02 score со средним опубликованной таблицы за три дня.
Искусственные инъекции проверяют реакцию на изменения, не качество обнаружения реальных атак.
Кластерная замена в инъекциях использует KMeans8 по замороженным train-векторам
для выбора другого поведения; отдельный продукт с HDBSCAN/UMAP здесь не создавался.

## Повторить

```bash
.venv/bin/python -m pip install -r experiments/dc_sage/requirements.txt
.venv/bin/python -m experiments.dc_sage.run prepare
.venv/bin/python -m experiments.dc_sage.run features
.venv/bin/python -m experiments.dc_sage.run baselines
.venv/bin/python -m experiments.dc_sage.run pilot
.venv/bin/python -m experiments.dc_sage.run train
.venv/bin/python -m experiments.dc_sage.inductive prepare
.venv/bin/python -m experiments.dc_sage.inductive train
.venv/bin/python -m experiments.dc_sage.anomalies prepare
.venv/bin/python -m experiments.dc_sage.run freeze
.venv/bin/python -m experiments.dc_sage.run evaluate
.venv/bin/python -m experiments.dc_sage.inductive evaluate
.venv/bin/python -m experiments.dc_sage.anomalies evaluate
.venv/bin/python -m experiments.dc_sage.report
```

Для отдельного повторения всем командам передайте один новый `--workdir`.
`prepare --source` принимает канонический CSV, чьё окно целиком покрывает нужные
интервалы и чей манифест подтверждает тот же исходный архив. Сырые bz2 сначала
нужно подготовить штатным пайплайном проекта.

Применить экспортированную модель к новому каноническому CSV:

```bash
.venv/bin/python -m experiments.dc_sage.predict \
  --model-dir runs/dc_sage/export \
  --preprocessor runs/dc_sage/export/preprocessor.pkl \
  --flows new_window.csv --window 131400:135000 \
  --output runs/new_embeddings.csv
```

Рядом с CSV сохраняются `.parts.npz` с собственным и графовым блоками.
Проверки: `.venv/bin/python -m pytest -q methods/graph/test_dc_sage.py`.

Основной отчёт хранит сводки. Подробные per-seed JSON и истории при пересборке отчёта пишутся в `runs/dc_sage/report_details/`, который исключён из git.
