# Decoupled Multiday: локальный эксперимент

Исследовательская реконструкция многодневной модели с отдельными блоками
идентичности, партнёров и графа. Это не исходный checkpoint
`multiday_codebook_plus`. Код в этой папке восстановлен из сохранённого
снимка на момент выбора модели. SHA основных файлов совпадают с записью
`runs/decoupled_multiday_local/experiment01/frozen_selection.json`, кроме
`base.py`: в его копии удалена пустая строка в конце, логика не менялась.

В обучении использованы отдельные часы дней 02, 03 и 04. Development и
локальный диагностический test — последующие окна дня 04, не отложенный день и
не общая таблица дней 14–16. Проверены пять seed (17, 29, 43, 71, 101):
локальный средний score **63,74 ± 0,45**. Ограничение сырого Neighbors@10
не ниже 0,222 не выполнено; лучшая из проверенных конфигураций сохранена для
диагностики, а не как прошедшая этот критерий модель.

Исходные данные, checkpoint, результаты и примеры конфигурации хранятся
локально в `runs/decoupled_multiday_local/`, не в Git. Проверка на новых
днях и официальный score этой версии не проводились. Подробные метрики по
seed находятся в `experiment01/report.json` и конфигурация — в
`experiment01/frozen_selection.json` в указанной папке.
