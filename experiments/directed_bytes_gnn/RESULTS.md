## Байты и граф

Для потока A=`src`, B=`dst`: у A исходящие += `bytes`/SrcBytes и входящие
+= `resp_bytes`/DstBytes; у B исходящие += `resp_bytes` и входящие += `bytes`.
Аналогично учитываются пакеты. Байты хоста включают и внешних партнёров;
графовые рёбра содержат только пары внутри source-когорты. Self-flow исключён.
Узловые признаки включают `log1p` отдельных входящих/исходящих байтов,
пакетов, количества строк с хостом в src/dst и числа соседей этих типов.

Два графовых слоя с обучаемыми параметрами обрабатывают четыре нормированные
матрицы сообщений: исходящие/входящие по числу потоков и
исходящие/входящие по объёму байтов. Есть отдельное преобразование собственных
признаков и skip-связь; представление GNN нормируется. Вектор модели —
`[512 координат замороженной основы; 0,5 × 64 координаты GNN]`.
Проверено, что каждый графовый канал влияет на выход, а графовые параметры
получают градиент. Точные объёмы байтов проверены на искусственных потоках в
обе стороны и с внешним узлом.

## Обучение и выбор

Исходное окно — день 02 11:00–12:00; дополнительные train-окна — дни
10, 11, 12 12:30–13:30. Обучаем 80 шагов, seed 17, AdamW. Нормировка
признаков обучена на активных хостах **только этих окон**. Контрастивная цель
сближает графовые представления одного хоста в разных train-окнах и отличает
их от других; host ID используется только для формирования обучающих меток.

Дополнительная голова предсказывает стандартизованный узловой профиль из
предыдущего окна и горизонта в 1 или 2 дня. В обучении используются пары
10→11, 10→12 и 11→12; вес SmoothL1-ошибки прогноза — 0,3. Также в
контрастивных парах участвует source02. Предсказание до дней 14–16 и
переобучение по этим дням не выполнялись. Схема mentor со скользящими
двенадцатидневными окнами и усреднением здесь **не реализована**: пользователь
отложил её до обновления данных и правил.

На уже изученном дне 13 сравнивались веса GNN 0,25 / 0,5 / 1; выбран 0,5.
Затем на том же весе оценены абляции. Score здесь — отдельная локальная
оценка дня 13, не среднее трёх тестовых дней:

| Development, день 13 | Score |
|---|---:|
| Исходная Similarity Graph Recent, 512 координат | 62,0684 |
| GNN с байтами и графовыми сообщениями | **63,3867** |
| Та же нейросеть с отключёнными сообщениями графа | 63,1672 |
| GNN без байтов в её собственных признаках и рёбрах | 63,1448 |

У модели без сообщений остаются собственные признаки узла и байты; параметры,
seed, число шагов и вес блока одинаковые. В контроле без байтов обнуляются
байтовые признаки **только новой GNN-ветки**; неизменённая исходная модель
также может учитывать байты. Приросты над абляциями малы, выбор весов и
контроли сделаны на одном уже исследованном development-окне. Их нельзя
считать статистическим доказательством на независимых днях.

Выбранный checkpoint, вес, хеши source/late и протокол зафиксированы до
построения benchmark-векторов; на днях 14–16 не проводились обучение или
подбор. Основа обучалась на тех же днях до 12, поэтому оценка на этих
исторических днях не является rolling-prefix псевдотестом. Для достоверной
оценки переноса нужны честные rolling-prefix модели и новый закрытый период.

## Артефакты

В `runs/directed_bytes_gnn_01/`: `training/gnn.pt` и JSON истории,
`development/frozen_selection.json`, `windows/`, `benchmark_submission/`,
`benchmark_result.json`. Базовые модель и late-векторы находятся в
`runs/similarity_graph_recent/`; для построения модели с нуля требуется также
этот фиксированный checkpoint. Данные, веса и векторы в Git не включаются.

Пример повторения из корня проекта. Каждая выходная папка должна быть новой;
предполагается, что базовый checkpoint уже находится в `runs/`:

```sh
python -m experiments.directed_bytes_gnn.prepare_windows --part development --output runs/my_gnn/windows
python -m experiments.directed_bytes_gnn.train --windows runs/my_gnn/windows --output runs/my_gnn/training --steps 80 --seed 17
python -m experiments.similarity_graph.infer \
  --checkpoint runs/similarity_graph_recent/refine01/model.joblib \
  --source runs/similarity_graph_recent/refine01/source.csv \
  --flows PT_PROJECT_ML/fingerprint_recent/day13/flows/test.csv \
  --start 1081800 --end 1085400 --day 13 \
  --cache runs/similarity_graph_recent/cache --output runs/my_gnn/baseline_day13.csv
python -m experiments.directed_bytes_gnn.evaluate_dev --run runs/my_gnn
# Только после сохранения development/frozen_selection.json:
python -m experiments.directed_bytes_gnn.prepare_windows --part benchmark --output runs/my_gnn/windows
python -m experiments.directed_bytes_gnn.benchmark --run runs/my_gnn
```

Для локальной оценки нужны эталон дня 13 с `neighbor_ceiling` из подготовки
Similarity Graph и ранний fit-эталон Links: пути заданы в `evaluate_dev.py`.
Стандартный `evaluation.submit` затем применяется к папке-карточке с четырьмя
CSV из `benchmark_submission/`. Команды не скачивают данные и не создают PR.
