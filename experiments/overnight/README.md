# Ночной перебор

Один запуск на ночь на обычной машине (16 ГБ памяти хватает): подготовить данные, перебрать много вариантов
`temporal_encoder` + «веер по сервису», выбрать лучший по validation и один раз проверить его на test.

## Запуск

```bash
# данные уже подготовлены (папка processed с flows/ и окнами таблицы)
PT_DATA=/путь/processed experiments/overnight/run.sh /путь/к/папке 8

# данных нет — скачать дни 02–04 и подготовить (≈ 15 ГБ на диске, токен — форма https://csr.lanl.gov/data/2017/)
LANL_TOKEN=<токен> NOTE="форма LANL, <дата>, <кто>" experiments/overnight/run.sh /путь/к/папке 8

# сначала проверка за ~10 минут
SMOKE=1 PT_DATA=/путь/processed experiments/overnight/run.sh /путь/к/папке
```

Второй аргумент — сколько часов перебирать (по умолчанию 8), потом итог. Если прервать (Ctrl+C, сон, перезагрузка),
повторный запуск продолжит с места остановки: сделанные пробы лежат в `runs/overnight/trials.jsonl`.

Итог — `runs/overnight/REPORT.md` и отправка `scoreboard/submissions/overnight_best/` с карточкой.

Запуск через агента на другой машине — `AGENT.md`.

## Что перебирается

| что | варианты | обучение заново? |
|---|---|---|
| куски train, эпохи | 2 / 3 / 4 куска, 5 / 10 / 20 / 40 эпох | да |
| ансамбль нейросетей | 1 или 3 зерна | да |
| веса частей | поведение 3–5, нейросеть 1.5–3, веер 0–0.75, диффузия 0–0.5, context 0–0.25, peers 0.75–1 | нет |
| длина PCA | 256 / 384 / 512 | нет |

10 вариантов обучения × 24 набора весов = 240 проб; одна проба ≈ 1–2 минуты.

## Безопасность машины

- приоритет `nice 15`: остальные программы идут первыми;
- не больше половины ядер и не больше 4 потоков;
- перед каждой пробой: свободная память ≥ 2 ГБ, место на диске ≥ 5 ГБ, нет перегрева
  (macOS: `pmset -g therm`, лимит частоты < 80% — пауза; Linux: датчики > 85 °C — пауза);
  не улучшилось за 15 минут — остановка с итогом по сделанному;
- пауза 20 секунд между пробами;
- на macOS `caffeinate -i` не даёт машине уснуть, пока идёт перебор. Ноутбук — на зарядке и не в закрытой сумке.

## Честно о результате

Подбор идёт только по validation, test смотрится один раз в конце. Чем больше проб, тем выше риск, что лучшая
на validation окажется хуже на test — поэтому в итоге видно и то и другое. Перебор весов и обучения в рамках
текущих правил дал за день +0.3 на test (`temporal_encoder_fan`); от ночи разумно ждать единиц, а не десятков баллов.
Узкое место — Identity на днях 03–04, его поднимет только обучение на нескольких днях, а это меняет правила таблицы.
