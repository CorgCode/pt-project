# Лидер + линейный графовый блок

Новый эксперимент: вектор `temporal_encoder_tuned` дополняется признаками соседей.
Графовая нейросеть для добавки не обучается; исходный лидер уже содержит MLP.

## Метод

1. Лидер восстанавливается по опубликованному `params.json`, без нового подбора его настроек.
2. Графовый блок: `[X | 0.5·A·X] → SVD-64`. `A` строится из направленных счётчиков
   как `C+Cᵀ`, self-связи удаляются, веса — `log1p(count)`, нормировка строки с
   нижней границей знаменателя 1. `X` — 95 замороженных признаков прежнего DC-SAGE.
3. Блоки приводятся к одинаковой средней длине по train. Графовый блок центрируется
   средним train. Склеиваются `[leader/scale | α·(graph−mean)/scale]`.
4. PCA обучается только на train и сжимает результат до **384 координат**, как у лидера.
5. При `α=0` векторы лидера сохраняются точно, PCA не применяется.

Новая реализация линейного блока проверяется численно против сохранённых векторов
предыдущего опыта. Веса PCA/SVD и нормировки замораживаются для следующих окон.
Объединение происходит по `host_id`; порядок строк не важен, пропущенные хосты — ошибка.

## Запуск

```bash
.venv/bin/python -m experiments.hybrid_dc.run all
```

Стадии отдельно: `prepare`, `leader`, `tune`, `evaluate`.
Для нового независимого запуска передайте `--workdir runs/другое_имя`.
Сетка весов задана заранее: **0, 0.1, 0.25, 0.5, 1, 2**.
Выбор — по штатному validation score. Test оценивается после сохранения выбора.
Повторный подбор в том же рабочем каталоге не выполняется.

Нужны локальные потоки дня 02 (`data/processed/flows/train.csv` с широким окном)
и материалы предыдущего опыта в `runs/dc_sage/`: `features.pkl`, `cache/manifest.json`,
папки `submissions/linear/` и `baselines_validation/linear/`.
Последний путь меняется через `--graph-dir`.
Подготовка проверяет границы, число потоков и события каждого хоста по общей когорте.

## Применение к готовым векторам нового окна

```bash
.venv/bin/python -m experiments.hybrid_dc.predict \
  --model runs/leader_graph_hybrid/export/fusion.joblib \
  --leader leader_window.csv --graph graph_window.csv \
  --output runs/hybrid_window.csv
```

Оба входа должны быть получены теми же замороженными моделями, что использовались
на train. Формат: `host_id,emb_0,...`. Выход сохраняет размерность лидера.
