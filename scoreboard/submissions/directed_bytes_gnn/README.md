# directed_bytes_gnn

## Кратко

Гибрид замороженной `similarity_graph_recent` и обучаемой направленной
графовой нейросети, отдельно учитывающей входящие и исходящие байты хостов.
Все пять метрик оценены на общих окнах дней 14–16: средний score **64,81**.
Код и подробные результаты — [`experiments/directed_bytes_gnn/`](../../../experiments/directed_bytes_gnn/RESULTS.md).

## Архитектура

К 512 координатам существующей модели добавляются 64 координаты GNN с
весом 0,5; итоговая размерность 576. Два слоя GNN имеют обучаемые
преобразования и коэффициенты для четырёх типов сообщений: исходящих и
входящих соседей по числу потоков и по объёму байтов. Дополнительно есть
преобразование признаков самого узла и skip-связь. Графовая ветвь не содержит
таблицы обучаемых собственных ID хостов.

Для каждого потока `src → dst` признаки хоста учитывают `bytes` и
`resp_bytes` в обе стороны: у src это соответственно переданные и принятые
байты; у dst — принятые и переданные. Узловые суммы включают партнёров вне
когорты; сообщения графа передаются только между хостами когорты.

## Данные

Исходная когорта 6453 хостов и source-окно — день 02 11:00–12:00;
дополнительное обучение — окна 12:30–13:30 дней 10, 11, 12. Подбор на
дне 13; тест на днях 14–16 после фиксации. Дней 01–09 в дополнительном
обучении GNN нет; схема скользящих 12-дневных окон не применялась.
Базовая `similarity_graph_recent` также обучена по истории до дня 12.

## Обучение и подбор

Один seed, 80 шагов AdamW. Контрастивная цель сближает один хост в разных
обучающих окнах и отличает его от других; собственный ID служит меткой, не
признаком. Дополнительная голова по представлению предсказывает признаки на
один или два дня вперёд в парах 10→11, 10→12 и 11→12; её вес в loss 0,3.
Нормировка подбиралась на обучающих окнах. По дню 13 выбран вес GNN 0,5 из
0,25 / 0,5 / 1; контроль без нового GNN также рассчитан. Новые параметры
не обучались и не выбирались по дням 14–16.

## Ограничения

Дни 13–16 ранее изучались; это не новый независимый тест, и один seed не
показывает устойчивость. На дне 13 проверки без графовых сообщений и без
байтов в GNN дали близкие score; байты и графовая информация могут оставаться
в фиксированной основе. Истинные роли не размечены. Потоки, веса и векторы
не входят в Git, для воспроизведения нужны локальные артефакты основы и GNN.
