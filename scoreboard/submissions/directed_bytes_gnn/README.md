# directed_bytes_gnn

## Кратко

К замороженной Similarity Graph Recent512 добавлена направленная GNN64.

## Архитектура

[base512; 0.5×gnn64]. Два графовых слоя агрегируют out/in count и bytes, вход узла — восемь TX/RX агрегатов. Исторический source и late используют одну обученную сеть.

Код и запуск: [experiments/directed_bytes_gnn](../../../experiments/directed_bytes_gnn/README.md).

## Данные

LANL NetFlow, 6453 известных хоста. История: по часу 02,10,11,12. Исходные частоты голосования — час дня02. Проверка на канонических часах дней14–16.

## Обучение и подбор

80 шагов AdamW; междневной InfoNCE +0.3 прогноза будущего профиля; вес0.5 выбран на development13. Все пять обязательных метрик рассчитаны; поздние векторы используются только для Identity после штатного Procrustes.

## Ограничения

Один seed, дни13–16 уже изучались, независимого закрытого holdout нет. История отличается от одночасовых baseline. Веса и embedding CSV локальные. Интервалы отдельных метрик — диапазон трёх окон. Доверительный интервал score не оценивался и не показывается; bootstrap не выполнялся.
