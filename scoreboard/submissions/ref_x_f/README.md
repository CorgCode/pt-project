# ref_x_f

## Кратко

Склейка четырёх описаний хоста: профиль поведения, "с кем общается" (TF-IDF), "какими сервисами пользуется" (TF-IDF) и эмбеддинг графовой нейросети (GraphSAGE с признаками рёбер). Веса блоков подобраны на validation.

## Архитектура

Вектор = [поведение ×1, собеседники ×0.25, сервисы ×0.04, GNN ×0.48]. Каждый блок перед умножением приведён к среднему квадрату длины 1, поэтому доли блоков в векторе: поведение (профиль) 77%, собеседники (TF-IDF) 5%, сервисы (TF-IDF) 0%, GNN-эмбеддинг 18%. Собеседники и сервисы — логарифм числа потоков, TF-IDF по хостам, SVD (128 и 64 компонент). GNN — готовый эмбеддинг из `runs/submissions/xb_s`.

## Данные

Поля src, dst, dst_port, proto, счётчики. Словари, IDF, SVD и нейросеть обучаются на train-окне и применяются к остальным окнам с теми же осями координат.

## Обучение и подбор

Подбор весов блоков и длины SVD — Optuna (30 проб). Балл на validation по задачам: 52.6 (Behavior 92, Future links 20, Shared partners 93, Identity 45). Без GNN: 49.0 (Behavior 97, Future links 18, Shared partners 93, Identity 36). Без TF-IDF (поведение + GNN): 52.0 (Behavior 94, Future links 19, Shared partners 93, Identity 44). Только поведение: 43.9 (Behavior 100, Future links 17, Shared partners 94, Identity 23).

## Ограничения

Подбор сделан на одном validation-окне сразу после train. Блок GNN обучается отдельно и в склейке не дообучается. Направление связи в GNN не используется.
