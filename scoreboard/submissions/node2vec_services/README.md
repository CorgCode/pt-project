# node2vec_services

## Кратко

node2vec на графе «хост — сервис» с ослаблением хабов. Лучший графовый метод в таблице.

## Архитектура

Граф и веса — как у `deepwalk_services`. Блуждания node2vec с p = 0.5, q = 2 (дольше держатся рядом с началом), 10 блужданий длины 80. Блуждания → skip-gram (word2vec для вершин): вершины, которые часто встречаются рядом в блужданиях, получают близкие векторы.
32 числа.

## Данные

Граф строится из потоков окна (`src`, `dst`, `dst_port`, `proto`, число потоков). Каждое окно обучается заново, поэтому координаты окон разные: для узнаваемости окна выравниваются поворотом (Procrustes) по половине хостов.

## Обучение и подбор

p и q подобраны на validation (`experiments.tune_methods`), test не использовался.

## Ограничения

Окна обучаются отдельно. В одиночку уступает `behavioral`, полезен в гибриде (`hybrid_services`).
