# node2vec_services

## Кратко

node2vec на графе с сервисами и подобранными параметрами блуждания. Сильнейший из чисто графовых методов.

## Архитектура

Граф — как у `deepwalk_services`: граф, где кроме хостов есть вершины-сервисы (протокол + порт, например `6/443` — HTTPS): хост соединён с сервисами, которыми пользуется (`uses`) и которые обслуживает (`serves`). Редкие сервисы выброшены. Вес ребра делится на корень из степеней концов, чтобы серверы, с которыми общаются все, не забирали все блуждания. Блуждания с p = 0.5, q = 2 (держатся ближе к началу), 10 штук длиной 80. Дальше — skip-gram, как у `deepwalk`. Вектор — 32 числа.

## Данные

Поля `src`, `dst`, `dst_port`, `proto` и число потоков. Граф строится заново по каждому окну, поэтому у каждого окна свои оси координат. Чтобы проверить узнаваемость (Identity), оси test-окна поворачивают к осям train по половине хостов (выравнивание Прокруста), а проверяют на другой половине.

## Обучение и подбор

p и q подобраны на validation, test не использовался.

## Ограничения

Окна обучаются отдельно. В одиночку уступает `behavioral`, но полезен как часть гибрида.
