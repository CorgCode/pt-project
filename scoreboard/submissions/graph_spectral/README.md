# graph_spectral

## Кратко

Спектральный эмбеддинг графа общения: хосты из одного «сообщества» получают близкие векторы.

## Архитектура

Граф «хост — хост» всего окна (вес ребра — log1p числа потоков), нормированная матрица смежности D^-1/2 A D^-1/2 → 16 главных сингулярных векторов, умноженных на корень из сингулярных чисел.

## Данные

Граф строится из потоков окна (`src`, `dst`, число потоков). Каждое окно обучается заново, поэтому координаты окон разные: для узнаваемости окна выравниваются поворотом (Procrustes) по половине хостов.

## Обучение и подбор

Обучения в смысле подбора нет: одно разложение (SVD) на окно. Размерность 16 задана заранее.

## Ограничения

Хорош на Pairs (общие собеседники), но почти не узнаёт хосты во времени: окна разлагаются независимо.
