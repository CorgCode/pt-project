# deepwalk_services

## Кратко

DeepWalk на графе «хост — сервис»: хосты с одинаковыми сервисами оказываются рядом.

## Архитектура

Граф: рёбра «хост — хост» и «хост — сервис» (`uses:proto/port` у инициатора, `serves:proto/port` у получателя; редкие сервисы выброшены). Вес ребра `hub_norm`: log1p, делённый на корень из степеней концов, — хабы меньше забирают блуждания. 10 блужданий длины 80. Блуждания → skip-gram (word2vec для вершин): вершины, которые часто встречаются рядом в блужданиях, получают близкие векторы.
32 числа.

## Данные

Граф строится из потоков окна (`src`, `dst`, `dst_port`, `proto`, число потоков). Каждое окно обучается заново, поэтому координаты окон разные: для узнаваемости окна выравниваются поворотом (Procrustes) по половине хостов.

## Обучение и подбор

Граф и вес выбраны по validation-баллу (#79). Остальное — по статье.

## Ограничения

Окна обучаются отдельно — узнаваемость слабая. Размерность 32, больше, чем у графовых методов на 16.
