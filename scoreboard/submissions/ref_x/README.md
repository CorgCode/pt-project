# ref_x

## Кратко

Склейка четырёх описаний хоста: профиль поведения, "с кем общается" (TF-IDF), "какими сервисами пользуется" (TF-IDF) и блок из двух частей без обучения: случайная проекция полных TF-IDF-таблиц (отпечаток) и усреднённые по рёбрам сервисы соседей (диффузия). Веса блоков подобраны на validation.

## Архитектура

Вектор = [поведение ×1, собеседники ×0.23, сервисы ×0.51, отпечаток и диффузия ×0.52]. Каждый блок перед умножением приведён к среднему квадрату длины 1, поэтому доли блоков в векторе: поведение (профиль) 63%, собеседники (TF-IDF) 3%, сервисы (TF-IDF) 16%, GNN-эмбеддинг 17%. Собеседники и сервисы — логарифм числа потоков, TF-IDF по хостам, SVD. Отпечаток: TF-IDF по собеседникам и сервисам без сжатия SVD, умножается на случайную гауссову матрицу (зерно 0) и сводится к 128 и 64 числам. Диффузия: TF-IDF-строки сервисов соседей усредняются по рёбрам графа окна с весом log(1 + число потоков), отдельно для исходящих и входящих рёбер, затем проекция на 32 числа каждая.

## Данные

Поля src, dst, dst_port, proto, счётчики, bytes, packets, ts. Словари, IDF, SVD обучаются на train-окне и применяются к остальным окнам с теми же осями координат.

## Обучение и подбор

Подбор весов блоков и длины SVD — Optuna (0 проб). Балл на validation по задачам: 51.8 (Behavior 86, Future links 19, Shared partners 93, Identity 47). Без 4-го блока: 49.6 (Behavior 90, Future links 18, Shared partners 93, Identity 40). Без TF-IDF (поведение + отпечаток и диффузия): 51.8 (Behavior 91, Future links 19, Shared partners 93, Identity 45). Только поведение: 43.7 (Behavior 98, Future links 17, Shared partners 94, Identity 23).

## Ограничения

Подбор сделан на одном validation-окне сразу после train. Анонимные порты в диффузии слиты в один токен.
