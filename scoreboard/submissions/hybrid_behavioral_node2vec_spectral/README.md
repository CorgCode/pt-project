# hybrid_behavioral_node2vec_spectral

## Кратко

Склейка готовых методов: `behavioral` ×1 + `node2vec` ×1 + `graph_spectral` ×1. Каждый метод замечает своё, вместе они описывают хост полнее.

## Архитектура

Векторы частей ([`behavioral`](../behavioral/README.md), [`node2vec`](../node2vec/README.md), [`graph_spectral`](../graph_spectral/README.md)) ставятся друг за другом в один длинный вектор. Перед этим каждая часть приводится
к одному масштабу (среднее 0, средняя длина 1), чтобы ни одна не перевешивала только из-за величины чисел,
и умножается на свой вес: чем больше вес, тем сильнее часть влияет на сходство хостов.

## Данные

Те же, что у частей: всё строится только по train-окну. Вектор test-окна — склейка test-векторов частей.

## Обучение и подбор

Своего обучения нет. Веса равные, не подбирались.

## Ограничения

Наследует слабые места частей. Вектор длиннее, чем у одиночных методов, поэтому сравнение с ними — не при равной длине.
