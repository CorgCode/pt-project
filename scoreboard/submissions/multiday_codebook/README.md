# multiday_codebook

## Кратко

Модель, обученная на истории дней 02–12, а не на одном часе дня 02. Для каждого известного компьютера учится
свой вектор («профиль источника»), а отдельный адаптер переводит трафик любого окна в то же пространство.
Код: [`experiments/multiday/`](../../../experiments/multiday/README.md).

## Архитектура

1. Кодировщик трафика на 32 часовых окнах (часы 10–13 дней 02–09): поведение, хешированные счётчики
   собеседников и сервисов, TF-IDF, две MLP-головы; итог — 896 чисел.
2. Профили источника: 896 чисел на каждый из 6453 компьютеров когорты, начальное значение — вектор
   кодировщика на дне 02. Учатся так, чтобы по похожим профилям угадывались будущие собеседники (дни 03–12),
   со штрафом за изменение прежних соседств.
3. Адаптер трафика: Ridge из вектора кодировщика окна в пространство профилей, свежие дни весят больше
   (полураспад 3 дня).

Train-вектор компьютера — его профиль; вектор в любом другом окне — адаптер от трафика этого окна. 896 чисел.

## Данные

Поля src, dst, dst_port, proto, bytes, packets, ts, duration. **Обучение — дни 02–12**, в том числе часы
12:00–14:00, поэтому на прежних test-окнах дней 02–04 модель не оценивается. Test-окна таблицы — дни 14–16,
их модель не видела. Когорта — та же, 6453 компьютера.

## Обучение и подбор

Цепочка из пяти этапов, у каждого выбор на своём validation-дне и один раз закрытый test-день
(подробно — README кода). Итоговый выбор — на дне 13: вес штрафа соседства 1, 400 шагов, смесь адаптера 0.5.
Модель зафиксирована (хеши кода и весов) до первого чтения дня 14.

## Ограничения

Учится на десяти днях, остальные модели таблицы — на одном часе: часть прироста — просто больше данных.
Профиль есть только у компьютеров, известных на обучении: новый компьютер так не закодировать.
Модель — 1.3 ГБ, в git не хранится.
