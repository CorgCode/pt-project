# direct_identity_codebook

## Кратко

Линейная поправка к позднему вектору оригинального codebook896. Source заморожен.

## Архитектура

y = y0 + W[y0; 0_64] + bias; нулевая инициализация. Codebook объединяет traffic-MLP384, две token-Bag головы256+256 и source-таблицу; поздний Ridge переводит трафик в её координаты. Поправка меняет только late-вектор.

Код и запуск: [experiments/temporal_donor_identity](../../../experiments/temporal_donor_identity/README.md).

## Данные

LANL NetFlow, 6453 известных хоста. История: 03–12; основа использует историю 02–12. Исходные частоты голосования — час дня02. Проверка на канонических часах дней14–16.

## Обучение и подбор

episodic Procrustes/CE и штраф отклонения от исходного late; checkpoint выбран на development13. Все пять обязательных метрик рассчитаны; поздние векторы используются только для Identity после штатного Procrustes.

## Ограничения

Один seed, дни13–16 уже изучались, независимого закрытого holdout нет. История отличается от одночасовых baseline. Веса и embedding CSV локальные. Сохранена штатная оценка прежней ветки вместе с рассчитанными там интервалами.
