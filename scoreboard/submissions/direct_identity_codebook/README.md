# direct_identity_codebook

## Кратко

Линейная поправка к поздним векторам оригинального многодневного
`multiday_codebook`. Source-профили остаются неизменными; цель — проверить,
можно ли улучшить узнаваемость хоста без изменения донорских соседей.

## Архитектура

Исходная основа даёт source-векторы и поздние векторы по 896 координат.
Применяется `y_new = y_base + W·y_base + b`: линейная поправка инициализируется
нулями и обучается на исторических окнах. Дополнительные признаки и MLP в
этом варианте не применяются. Векторы остальных четырёх задач не изменяются.

## Данные

LANL NetFlow, исходная когорта6453 с train-окна дня02 11:00–12:00. Исходный
кодировщик и поправка используют разрешённую историю до дня12; адаптер
применяется к трафику соответствующего позднего окна. Служебные host_id
используются для сопоставления меток, но не как входные признаки поправки.

## Обучение и подбор

Заморожена оригинальная основа до12. Поправка обучена на десяти сохранённых
часовых окнах дней03–12, по 768 активных хостов на шаг, 160 шагов, AdamW;
calibration/evaluation внутри обучающего эпизода, stop-gradient через
Procrustes. На ранее изученном дне13 по официальной Identity выбран первый
лучший checkpoint, шаг40, до фиксированной оценки окон дней14–16. Данные
дня13 не использованы для градиента или refit. Параметры в `params.json`.
Код, сценарий и проверка — `experiments/temporal_donor_identity/`.

## Ограничения

Это слабый предварительный результат: данные обучения residual видела базовая
модель, независимые rolling-prefix основы не обучены, день13 уже изучался,
выбор из21 checkpoint на одном окне и один seed. Дни14–16 также уже изучены;
нужен ранее закрытый период. Оценка чувствительна к точности CSV при
недоопределённом Procrustes: вектора нужно оценивать штатным reader. Код и
результаты не восстанавливают `multiday_codebook_plus`: его голова отсутствует.
Checkpoint основы и новые веса локальные и не поставляются в Git; CI на чистом
checkout не сможет самостоятельно пересоздать CSV. Источник таблицы —
сохранённый JSON результата, проверенный локально штатным evaluation.submit.
Цель score80 не достигнута. Оценка проведена на ранее изученных окнах.
