# behavioral_pca

## Кратко

`behavioral`, сжатый до 16 чисел методом главных компонент (PCA).

## Архитектура

Профиль `behavioral` (57) → PCA, 16 компонент.

## Данные

Поля `src`, `dst`, `dst_port`, `proto`, `bytes`, `packets`, `ts` train-окна. Кто именно собеседники — не используется, только их число.
Список портов и протоколов берётся из train. Для других окон те же колонки, но среднее и разброс каждой — по своему окну (окна разной длины: час и полчаса).

## Обучение и подбор

PCA обучается один раз на train и применяется ко всем окнам (одна система координат). Размерность 16 — общая для графовых методов, чтобы сравнивать при равной размерности.
