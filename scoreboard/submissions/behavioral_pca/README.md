# behavioral_pca

## Кратко

`behavioral`, сжатый с 57 до 16 чисел. Нужен, чтобы сравнивать с графовыми методами при одинаковой длине вектора.

## Архитектура

Профиль `behavioral` (57 чисел) → метод главных компонент (PCA): оставляет 16 направлений, вдоль которых хосты различаются сильнее всего.

## Данные

Те же поля, что у `behavioral`.

## Обучение и подбор

PCA обучается один раз на train и применяется ко всем окнам, поэтому у всех окон одни оси координат. 16 — длина вектора у графовых методов.

## Ограничения

Сжатие теряет часть информации, поэтому балл ниже, чем у полного `behavioral`.
