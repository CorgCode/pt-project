# behavioral_dae

## Кратко

`behavioral_dae` — небольшой нейросетевой бейзлайн: многослойный автоэнкодер с узким скрытым слоем преобразует профиль сетевого поведения компьютера в вектор из 16 чисел. Для обучения не нужна разметка.

## Архитектура

Вход — поведенческий профиль из существующего `BehavioralBaseline`. Нейросеть имеет архитектуру `n_features → 64 → 16 → 64 → n_features`. Encoder строит эмбеддинг из 16 чисел, decoder восстанавливает вход. Это denoising autoencoder: при обучении к входу добавляется небольшой гауссов шум, а сеть восстанавливает чистые признаки. Оптимизируется MSE реконструкции с AdamW.

## Данные

Используются поля потоков через текущий код проекта: `src`, `dst`, `dst_port`, `proto`, `bytes`, `packets`, `ts`. Признаки включают объём и направление трафика, число собеседников, распределение портов и протоколов, почасовую активность. Обучение — только по train. Для validation и всех test-окон применяется одна и та же обученная сеть; файл `SHARED_COORDINATES` фиксирует общие координаты.

## Обучение и подбор

Начальная конфигурация: embedding dim=16, hidden dim=64, 30 эпох, batch size=256, learning rate=0.001, noise std=0.10, seed=17. Параметры не объявляются оптимальными; подбор должен проводиться только на validation по общему score проекта. Зависимость: PyTorch (`pip install torch`).

## Ограничения

Автоэнкодер минимизирует ошибку реконструкции поведенческих признаков, а не расстояние между одним хостом в разные моменты времени. Входные признаки пересекаются с поведенческим эталоном соседей, поэтому этот результат — бейзлайн/калибровка, а не независимое подтверждение семантики эмбеддингов. На настоящем LANL результаты должны быть измерены после запуска скрипта.
