# gnn_tfidf_new

## Кратко

Склейка четырёх описаний хоста: профиль поведения, "с кем общается" (TF-IDF), "какими сервисами пользуется" (TF-IDF) и эмбеддинг графовой нейросети (GraphSAGE с признаками рёбер). Веса блоков подобраны на validation.

## Архитектура

Вектор = [поведение ×1, собеседники ×2.12, сервисы ×1.81, GNN ×1.26]. Каждый блок перед умножением приведён к среднему квадрату длины 1, поэтому доли блоков в векторе: поведение (профиль) 10%, собеседники (TF-IDF) 43%, сервисы (TF-IDF) 32%, GNN-эмбеддинг 15%. Собеседники и сервисы — логарифм числа потоков, TF-IDF по хостам, SVD (256 и 128 компонент). GNN — готовый эмбеддинг из `runs/submissions/gnn_new`.

## Данные

Поля src, dst, dst_port, proto, счётчики. Словари, IDF, SVD и нейросеть обучаются на train-окне и применяются к остальным окнам с теми же осями координат.

## Обучение и подбор

Подбор весов блоков и длины SVD — Optuna (15 проб). Балл на validation по задачам: 46.3 (Behavior 60, Future links 18, Shared partners 85, Identity 49). Без GNN: 45.8 (Behavior 56, Future links 18, Shared partners 87, Identity 49). Без TF-IDF (поведение + GNN): 38.1 (Behavior 66, Future links 17, Shared partners 63, Identity 29). Только поведение: 37.4 (Behavior 64, Future links 16, Shared partners 71, Identity 26).

## Ограничения

Подбор сделан на одном validation-окне сразу после train. Блок GNN обучается отдельно и в склейке не дообучается. Направление связи в GNN не используется.
