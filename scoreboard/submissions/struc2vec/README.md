# struc2vec

## Кратко

struc2vec (2017): близкими считаются хосты с похожим *устройством* окрестности, даже если они в разных концах сети.

## Архитектура

Для каждого хоста — степени соседей на расстоянии 1, 2, 3 шага. Хосты сравниваются по этим спискам (DTW — сравнение последовательностей разной длины). Из сравнений строится граф похожести, по нему — блуждания (10 × 80) и skip-gram, как у `deepwalk`. Вектор — 16 чисел.

## Данные

Поля `src`, `dst` и число потоков. Граф строится заново по каждому окну, поэтому у каждого окна свои оси координат. Чтобы проверить узнаваемость (Identity), оси test-окна поворачивают к осям train по половине хостов (выравнивание Прокруста), а проверяют на другой половине.

## Обучение и подбор

Параметры — как в статье, не подбирались. Самый долгий метод.

## Ограничения

Почти случайный в задачах про собеседников и узнаваемость: похожее устройство окрестности — не то, что проверяют эталоны.
