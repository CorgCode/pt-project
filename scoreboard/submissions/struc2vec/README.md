# struc2vec

## Кратко

struc2vec (Ribeiro et al., 2017): хосты с похожей структурой окрестности рядом, даже если они в разных частях сети.

## Архитектура

Последовательности степеней в кольцах вокруг вершины, DTW-расстояния по 3 слоям → многослойный граф похожести → блуждания (10 × 80, вероятность остаться в слое 0.3) → skip-gram, 16 чисел.

## Данные

Граф строится из потоков окна (`src`, `dst`, число потоков). Каждое окно обучается заново, поэтому координаты окон разные: для узнаваемости окна выравниваются поворотом (Procrustes) по половине хостов.

## Ограничения

Самый слабый: почти случайный на Pairs и Identity. Структурная похожесть не совпадает с тем, что проверяют эталоны.
