# behavioral

## Кратко

Поведенческий профиль хоста: сколько трафика, со сколькими общается, какие порты и протоколы, когда активен. Простой и понятный бейзлайн.

## Архитектура

57 чисел, шесть блоков: объёмы (log1p потоков, байт, пакетов — исходящих и входящих), число собеседников, доля исходящего, распределение по 20 частым портам, по протоколам (вес 0.5), активность по 24 часам.
Каждый блок стандартизуется и делится на корень из числа колонок — у блоков одинаковый вклад.

## Данные

Поля `src`, `dst`, `dst_port`, `proto`, `bytes`, `packets`, `ts` train-окна. Кто именно собеседники — не используется, только их число.
Список портов и протоколов берётся из train. Для других окон те же колонки, но среднее и разброс каждой — по своему окну (окна разной длины: час и полчаса).

## Обучение и подбор

Обучать нечего: признаки считаются по формуле. Параметры (20 портов, веса блоков) заданы заранее, не подбирались.

## Ограничения

Те же признаки, что у эталона Neighbors (по другому окну), поэтому Neighbors у него ожидаемо высокий — это точка калибровки, а не независимое доказательство. Не знает, с кем именно общается хост.
