# behavioral

## Кратко

Описывает хост по тому, *как* он ведёт себя в сети: сколько трафика, со сколькими общается, через какие порты, в какие часы активен. Самый простой метод и точка отсчёта для остальных.

## Архитектура

57 чисел из шести групп:
1. объёмы — сколько потоков, байт и пакетов отправил и получил (в логарифме, чтобы большие хосты не задавили остальных);
2. со сколькими разными хостами общался;
3. какая доля трафика исходящая;
4. как трафик делится между 20 самыми частыми портами;
5. как делится между протоколами (TCP, UDP, …);
6. в какие часы суток активен (24 доли).

Каждая группа приводится к одному масштабу, чтобы ни одна не перевешивала.

## Данные

Поля `src`, `dst`, `dst_port`, `proto`, `bytes`, `packets`, `ts`. С кем именно общается хост — не используется, только сколько собеседников. Список портов берётся из train. Для любого окна считаются те же колонки; масштаб каждой — по своему окну, потому что окна бывают разной длины.

## Обучение и подбор

Обучать нечего: всё считается по формулам. Число портов и веса групп заданы заранее, не подбирались. Считается за секунды.

## Ограничения

Эталон задачи Behavior построен из похожих признаков (по другому окну), поэтому там он ожидаемо силён — это скорее калибровка, чем доказательство. Не знает, с кем именно общается хост, поэтому слабее в задачах про собеседников.
