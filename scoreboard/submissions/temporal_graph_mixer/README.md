# temporal_graph_mixer

## Кратко

Четыре блока признаков и временной MLP-Mixer; выбран no_graph_global_w2.

## Архитектура

Own128, peer TF-IDF128, service/context128 и diffusion128. Два Mixer-слоя объединяют четыре15-минутки; выход [own128;stable256;dynamic128]. Выбранная версия выключает графовый вход, веса1/1/1; source own от02, stable/dynamic усредняются по истории.

Код и запуск: [experiments/temporal_graph_mixer](../../../experiments/temporal_graph_mixer/README.md).

## Данные

LANL NetFlow, 6453 известных хоста. История: по часу каждого дня 02–12. Исходные частоты голосования — час дня02. Проверка на канонических часах дней14–16.

## Обучение и подбор

600 шагов междневного/прогнозного обучения и600 full-gallery CE; выбор на development13. Все пять обязательных метрик рассчитаны; поздние векторы используются только для Identity после штатного Procrustes.

## Ограничения

Один seed, дни13–16 уже изучались, независимого закрытого holdout нет. История отличается от одночасовых baseline. Веса и embedding CSV локальные. Интервалы отдельных метрик — диапазон трёх окон. Доверительный интервал score не оценивался и не показывается; bootstrap не выполнялся.
