# similarity_graph_recent

## Кратко

Обученная матрица сходства хостов, сжатая в 512 координат; частичное сопоставление позднего графа.

## Архитектура

Симметричная матрица объединяет behavior/peer TF-IDF. Координатный поиск учитывает top10 и реальные голоса дня02; компактная дистилляция сохраняет соседства. Late — смесь исторических source-профилей после совместного сопоставления графов.

Код и запуск: [experiments/similarity_graph](../../../experiments/similarity_graph/README.md).

## Данные

LANL NetFlow, 6453 известных хоста. История: по часу 02,10,11,12. Исходные частоты голосования — час дня02. Проверка на канонических часах дней14–16.

## Обучение и подбор

координатный поиск, компактная дистилляция и выбор на development13. Все пять обязательных метрик рассчитаны; поздние векторы используются только для Identity после штатного Procrustes.

## Ограничения

Один seed, дни13–16 уже изучались, независимого закрытого holdout нет. История отличается от одночасовых baseline. Веса и embedding CSV локальные. Интервалы отдельных метрик — диапазон трёх окон. Доверительный интервал score не оценивался и не показывается; bootstrap не выполнялся.
