# temporal_encoder_tuned

## Кратко

`temporal_encoder`, у которого настройки не взяты с дня 02, а подобраны заново на validation этого прогона. Код: [`scoreboard/temporal_encoder.py --tune`](../../temporal_encoder.py).

## Архитектура

Те же части, что у [`temporal_encoder`](../temporal_encoder/README.md): поведение, собеседники, сервисы, сервисы соседей и нейросеть, затем сжатие PCA до 384 чисел. Отличаются только веса частей и то, на сколько кусков режется train при обучении нейросети.

## Данные

Как у `temporal_encoder`: всё обучается только на train и применяется к любому окну — одни оси координат.

## Обучение и подбор

Train режется на 2 или 4 куска по времени. Чем больше кусков, тем больше примеров «тот же хост в другое время» видит нейросеть, но каждый кусок короче и шумнее. Для каждого варианта перебираются веса частей: поведение ×2 / ×3 / ×4, нейросеть ×0.5 / ×1 / ×2, сервисы соседей ×0 / ×0.5. Выбирается вариант с лучшим баллом на validation по всем четырём задачам; test при этом не используется. Выбранное — в `params.json`, вся сетка — в `tuning.json`. Нужен `pip install torch`.

## Ограничения

Validation — полчаса сразу после train того же дня, поэтому подбор может подстроиться под этот день. Насколько выбор переносится на другие дни, показывает раздел «По дням» в таблице.
