# ref_g

## Кратко

Склейка четырёх описаний хоста: профиль поведения, "с кем общается" (TF-IDF), "какими сервисами пользуется" (TF-IDF) и эмбеддинг графовой нейросети (GraphSAGE с признаками рёбер). Веса блоков подобраны на validation.

## Архитектура

Вектор = [поведение ×1, собеседники ×0.60, сервисы ×0.14, GNN ×0.18]. Каждый блок перед умножением приведён к среднему квадрату длины 1, поэтому доли блоков в векторе: поведение (профиль) 71%, собеседники (TF-IDF) 26%, сервисы (TF-IDF) 1%, GNN-эмбеддинг 2%. Собеседники и сервисы — логарифм числа потоков, TF-IDF по хостам, SVD (128 и 64 компонент). GNN — эмбеддинг: 128 чисел и 64 главные компоненты профиля из 66 признаков. Параметры GNN (hidden 256, lam 0.229, beta 2.04) взяты из подбора на старых окнах.

## Данные

Поля src, dst, dst_port, proto, счётчики, bytes, packets, ts. Словари, IDF, SVD и нейросеть обучаются на train-окне и применяются к остальным окнам с теми же осями координат.

## Обучение и подбор

Подбор весов блоков и длины SVD — Optuna (0 проб). Балл на validation по задачам: 50.2 (Behavior 86, Future links 19, Shared partners 92, Identity 43). Без GNN: 49.6 (Behavior 85, Future links 18, Shared partners 92, Identity 42). Без TF-IDF (поведение + GNN): 45.0 (Behavior 98, Future links 17, Shared partners 93, Identity 26). Только поведение: 43.7 (Behavior 98, Future links 17, Shared partners 94, Identity 23).

## Ограничения

Подбор сделан на одном validation-окне сразу после train. Блок GNN обучается отдельно и в склейке не дообучается. Направление связи в GNN не используется.
