# deepwalk

## Кратко

DeepWalk (2014): хосты, которые часто оказываются рядом при случайных прогулках по графу общения, получают близкие векторы.

## Архитектура

Берётся граф «кто с кем общается»: вершины — хосты, ребро — были потоки между ними, вес — log(1 + число потоков). По графу запускаются случайные блуждания: «шагаем» от хоста к его собеседникам, чаще — по рёбрам с большим числом потоков. Получаются цепочки хостов, как предложения из слов. Дальше — приём из word2vec (skip-gram): хосты, которые часто стоят рядом в цепочках, получают близкие векторы.

10 блужданий длиной 80 из каждого хоста, окно 10, вектор — 16 чисел.

## Данные

Поля `src`, `dst` и число потоков. Граф строится заново по каждому окну, поэтому у каждого окна свои оси координат. Чтобы проверить узнаваемость (Identity), оси test-окна поворачивают к осям train по половине хостов (выравнивание Прокруста), а проверяют на другой половине.

## Обучение и подбор

Параметры — как в статье, не подбирались. Несколько минут на окно.

## Ограничения

Окна обучаются отдельно, поэтому хост плохо узнаётся во времени. Серверы, с которыми общаются все, забирают большую часть блужданий.
