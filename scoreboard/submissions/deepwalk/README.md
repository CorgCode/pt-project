# deepwalk

## Кратко

DeepWalk (Perozzi et al., 2014): случайные блуждания по графу общения + skip-gram.

## Архитектура

Граф «хост — хост», вес ребра log1p числа потоков. 5 блужданий длины 80 из каждой вершины. Блуждания → skip-gram (word2vec для вершин): вершины, которые часто встречаются рядом в блужданиях, получают близкие векторы.
Окно 10, hierarchical softmax, 1 эпоха, 16 чисел.

## Данные

Граф строится из потоков окна (`src`, `dst`, число потоков). Каждое окно обучается заново, поэтому координаты окон разные: для узнаваемости окна выравниваются поворотом (Procrustes) по половине хостов.

## Обучение и подбор

Параметры — как в статье (кроме 5 блужданий вместо 10 — ради времени на ноутбуке). ~4–5 минут на окно.

## Ограничения

Окна обучаются отдельно, поэтому слабая узнаваемость. Хабы (серверы, с которыми общаются все) забирают блуждания.
