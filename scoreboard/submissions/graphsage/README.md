# graphsage

## Кратко

GraphSAGE (Hamilton et al., 2017): графовая нейросеть — вектор хоста собирается из признаков его соседей.

## Архитектура

Два слоя усреднения соседей (выборка 25 и 10 соседей), скрытый слой 64, выход 16. Входные признаки — поведенческий профиль хоста. Обучение без учителя: хосты, близкие в коротких блужданиях (длина 5, окно 2), сближаются, 20 случайных — отталкиваются.

## Данные

Граф «хост — хост» и поведенческие признаки train-окна. Индуктивный: веса обучаются один раз на train, другие окна встраиваются теми же весами — одна система координат.

## Обучение и подбор

Adam, lr 0.01, 2 эпохи, ~5 минут. Параметры — по статье, не подбирались.

## Ограничения

Нормировка признаков — по train, поэтому в окнах другой длины входы сдвинуты (как было у `behavioral` до исправления) — отсюда слабая узнаваемость.
