# graphsage

## Кратко

GraphSAGE (2017): графовая нейросеть — вектор хоста собирается из поведения самого хоста и его соседей.

## Архитектура

Вход — поведенческий профиль хоста. Два слоя: каждый усредняет векторы части соседей (25, потом 10) и смешивает со своим. Скрытый слой 64, выход 16. Обучение без меток: хосты, близкие при коротких блужданиях, сближаются, случайные — отталкиваются.

## Данные

Граф и поведенческие признаки train-окна. Веса нейросети обучаются один раз на train, другие окна пропускаются через ту же сеть — у всех окон одни оси координат.

## Обучение и подбор

Adam, 2 эпохи, несколько минут. Параметры — как в статье, не подбирались.

## Ограничения

Признаки нормируются по train, а окна бывают разной длины — входы других окон сдвинуты. Отсюда слабая узнаваемость.
