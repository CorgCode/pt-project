# temporal_cca_tuned

## Кратко

Лёгкая версия [`temporal_encoder`](../temporal_encoder/README.md): вместо нейросети — одна формула линейной алгебры. Без torch, обучается за секунды. Код: [`scoreboard/temporal_encoder.py --encoder cca --tune`](../../temporal_encoder.py).

## Архитектура

Те же признаки хоста, что у `temporal_encoder`: поведение, собеседники, сервисы, сервисы соседей, «собеседник + сервис», объёмы. Вместо нейросети — канонический корреляционный анализ (CCA): ищутся 128 направлений, по которым у одного и того же хоста в разных кусках train получаются одинаковые числа, а у разных хостов — разные. Чем устойчивее направление, тем больше его вес. Дальше — склейка с весами и сжатие PCA до 384 чисел, как у `temporal_encoder`.

## Данные

Поля `src`, `dst`, `proto`, `dst_port`, байты, пакеты, длительность. Всё обучается только на train и применяется к любому окну — одни оси координат.

## Обучение и подбор

Train режется на 2 или 4 куска по времени; CCA — одно разложение матрицы, секунды. Веса частей (поведение ×2 / ×3 / ×4, проекция ×0.5 / ×1 / ×2, сервисы соседей ×0 / ×0.5) и число кусков выбираются по баллу на validation по всем четырём задачам; test не используется. Выбранное — в `params.json`, вся сетка — в `tuning.json`.

## Ограничения

Линейная проекция проще нейросети: может хуже узнавать хост, если связь признаков во времени нелинейная. Подбор — на validation того же дня, что и train.
