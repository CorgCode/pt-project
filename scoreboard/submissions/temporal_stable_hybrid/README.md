# temporal_stable_hybrid

## Кратко

Линейный гибрид поведения, собеседников и сервисов с проекцией, устойчивой между временными срезами. Итоговый score на трёх общих test-окнах — **53,23** (дни 02 / 03 / 04: 54,40 / 54,26 / 51,01).

## Архитектура

Поведенческий профиль и направленные TF-IDF-профили собеседников и сервисов (SVD до 128 координат каждый) дополняются устойчивой проекцией до 128 координат. Проекция минимизирует изменение представления одного хоста между четырьмя срезами train при ограничении общей ковариации. Блоки нормируются по train и склеиваются с весами; итог — 441 координата. [Код](../../temporal_stable_hybrid.py).

## Данные

Поля src, dst, dst_port, proto, bytes, packets, ts; duration участвует в подготовке окон. Используются общие когорта (6453 хоста), окна и эталоны scoreboard. Словари, IDF, SVD, масштабы и проекция фиксируются на train дня 02. Дни 03 и 04 используются только для оценки; все окна имеют общие координаты.

## Обучение и подбор

Четыре среза train; пары взвешиваются корнем из числа потоков, минимум 5 потоков в срезе, регуляризация 0,1. На validation дня 02 проверяются веса поведения {2, 3} и проекции {0, 0,5, 1, 2}. Выбраны веса 2 / 2: validation score 49,40 против 48,50 без проекции. Вся сетка сохранена в [params.json](params.json). Для воспроизведения:

```bash
PT_COMPACT=1 PT_DATA=data/scoreboard_exact/processed \
  OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python scoreboard/temporal_stable_hybrid.py \
  --tune --output runs/temporal_stable_repro
python -m evaluation.submit scoreboard/submissions/temporal_stable_hybrid
```

Первая команда обучает модель и записывает новые векторы в runs; вторая оценивает приложенную посылку. Посылка содержит train и три test-файла, AUTHOR и SHARED_COORDINATES.

## Ограничения

Устойчивость может подавить полезные изменения, а редкие хосты имеют шумные признаки. Test просматривался при диагностике порядка поведенческих признаков; после исправления модель переобучена с прежней validation-сеткой. Это исследовательская оценка на известных окнах. Проверяется совпадение train-векторов до и после загрузки модели.
