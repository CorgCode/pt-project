# node2vec

## Кратко

node2vec (Grover & Leskovec, 2016): блуждания с перекосом (параметры p, q) + skip-gram.

## Архитектура

Граф «хост — хост», вес log1p. 5 блужданий длины 80. Блуждания → skip-gram (word2vec для вершин): вершины, которые часто встречаются рядом в блужданиях, получают близкие векторы.
Окно 10, negative sampling (5), 1 эпоха, 16 чисел.
В этой отправке p = q = 1 — это DeepWalk с negative sampling.

## Данные

Граф строится из потоков окна (`src`, `dst`, число потоков). Каждое окно обучается заново, поэтому координаты окон разные: для узнаваемости окна выравниваются поворотом (Procrustes) по половине хостов.

## Обучение и подбор

Подбор p, q по validation (`experiments.tune_methods`) нашёл p = 0.5, q = 2; эти значения используются в `node2vec_services`. Здесь — значения по умолчанию.

## Ограничения

Как у `deepwalk`: окна отдельно, хабы, узнаваемость слабая.
