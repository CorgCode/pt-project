# node2vec

## Кратко

node2vec (2016): как DeepWalk, но блуждания можно настроить — держаться ближе к началу или уходить далеко.

## Архитектура

Берётся граф «кто с кем общается»: вершины — хосты, ребро — были потоки между ними, вес — log(1 + число потоков). По графу запускаются случайные блуждания: «шагаем» от хоста к его собеседникам, чаще — по рёбрам с большим числом потоков. Получаются цепочки хостов, как предложения из слов. Дальше — приём из word2vec (skip-gram): хосты, которые часто стоят рядом в цепочках, получают близкие векторы. Параметры p и q задают, насколько блуждание любит возвращаться назад и уходить вглубь.

10 блужданий длиной 80, окно 10, вектор — 16 чисел. Здесь p = q = 1, то есть это DeepWalk с другим способом обучения (negative sampling).

## Данные

Поля `src`, `dst` и число потоков. Граф строится заново по каждому окну, поэтому у каждого окна свои оси координат. Чтобы проверить узнаваемость (Identity), оси test-окна поворачивают к осям train по половине хостов (выравнивание Прокруста), а проверяют на другой половине.

## Обучение и подбор

Подбор на validation нашёл p = 0.5, q = 2; эти значения — в `node2vec_services`. Здесь — значения по умолчанию.

## Ограничения

Как у `deepwalk`: окна отдельно, серверы-хабы, слабая узнаваемость.
