# hybrid_services

## Кратко

Гибрид: `behavioral` ×4 + `node2vec_services` ×1 + `graph_spectral` ×1. Части ловят разное, вместе — лучше, чем по отдельности.

## Архитектура

Векторы частей ([`behavioral`](../behavioral/README.md), [`node2vec_services`](../node2vec_services/README.md), [`graph_spectral`](../graph_spectral/README.md)) склеиваются (конкатенация). Перед склейкой каждая часть нормируется:
среднее 0, средняя длина вектора 1 — чтобы ни одна не перевешивала из-за масштаба. Затем умножается на свой вес.

## Данные

Те же, что у частей: всё строится только по train-окну. Вектор test-окна — склейка test-векторов частей.

## Обучение и подбор

Своего обучения нет. Вес первой части подобран по баллу на validation (`scoreboard/combine.py --tune-weights`), test при этом не используется.

## Ограничения

Наследует ограничения частей. Размерность — сумма размерностей частей, поэтому сравнение с одиночными методами
не при равной размерности.
