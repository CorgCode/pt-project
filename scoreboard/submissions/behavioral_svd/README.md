# behavioral_svd

## Кратко

`behavioral`, сжатый до 16 чисел через TruncatedSVD (без центрирования).

## Архитектура

Профиль `behavioral` (57) → TruncatedSVD, 16 компонент.

## Данные

Поля `src`, `dst`, `dst_port`, `proto`, `bytes`, `packets`, `ts` train-окна. Кто именно собеседники — не используется, только их число.
Список портов и протоколов берётся из train. Для других окон те же колонки, но среднее и разброс каждой — по своему окну (окна разной длины: час и полчаса).

## Обучение и подбор

SVD обучается один раз на train и применяется ко всем окнам. Размерность 16, как у графовых методов.

## Ограничения

Практически совпадает с `behavioral_pca`: признаки и так стандартизованы.
