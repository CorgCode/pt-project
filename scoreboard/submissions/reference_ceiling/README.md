# reference_ceiling

## Кратко

Подсказка «лучше нельзя» для задачи Behavior: в качестве вектора берётся сам эталон, посчитанный прямо по test-окну. В рейтинге не участвует.

## Архитектура

Поведенческий профиль (как у `behavioral`), но по test-окну, а не по train.

## Данные

Специально подглядывает в test, чтобы показать потолок. Векторов для узнаваемости нет, поэтому колонка Identity пустая.

## Обучение и подбор

Обучения нет.

## Ограничения

Это не метод. Даже у него New partners низкий — значит, это потолок самой задачи, а не слабость методов.
