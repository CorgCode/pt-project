# behavioral_dae_consistency

## Кратко

`behavioral_dae_consistency` — нейросетевой бейзлайн, который преобразует профиль сетевого поведения хоста в эмбеддинг из 16 чисел. Это вариант denoising autoencoder с дополнительным штрафом согласованности двух независимо зашумлённых представлений одного профиля.

## Архитектура

Используется архитектура `n_features → 64 → 16 → 64 → n_features`. Encoder строит латентный вектор, decoder восстанавливает исходный профиль. Для двух независимых шумовых представлений считаются две ошибки реконструкции и MSE между латентными векторами:

`L = 0.5 · (MSE(x̂1, x) + MSE(x̂2, x)) + λ · MSE(z1, z2)`.

Начальное значение `λ = 0.1`. Оптимизатор — AdamW, функция реконструкции — MSE.

## Данные

Используются поведенческие признаки из существующего `BehavioralBaseline`. Обучение и преобразования признаков используют только train-окно. Для validation и test применяется тот же обученный encoder; координаты эмбеддингов общие.

## Обучение и подбор

Начальная конфигурация: embedding dim=16, hidden dim=64, 30 эпох, batch size=256, learning rate=0.001, noise std=0.10, weight decay=1e-5, seed=17, consistency weight=0.1. Значение consistency weight — исходная экспериментальная настройка, не объявляется оптимальным. Подбор допустим только по validation; test используется для итогового сравнения. Зависимость: PyTorch (`pip install torch`).

## Ограничения

Штраф согласованности делает эмбеддинги двух шумовых представлений одного профиля ближе, но сам по себе не доказывает, что векторы отражают функциональные роли хостов. Чрезмерный вес штрафа может ухудшить информативность латентного пространства; его нужно оценивать вместе с reconstruction loss и метриками scoreboard. Результаты зависят от признаков BehavioralBaseline и протокола LANL.
