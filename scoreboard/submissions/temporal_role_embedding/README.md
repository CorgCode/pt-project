# Temporal Role Embedding v1 (TRE v1)

## Кратко

Temporal Role Embedding — CPU-модель эмбеддингов компьютеров в сети.

Модель объединяет поведенческие характеристики хоста и его положение
в направленном графе сетевых взаимодействий.

Код: [`scoreboard/temporal_role_embedding.py`](../../temporal_role_embedding.py).

## Архитектура

Эмбеддинг состоит из двух частей:

1. Behavior (10 признаков):
   - число исходящих и входящих потоков;
   - число уникальных собеседников;
   - число используемых и обслуживаемых сервисов;
   - общая активность;
   - доли исходящего и входящего трафика.

2. Temporal Role (64 признака):
   - направленный граф взаимодействий между хостами;
   - отдельные координаты для исходящих и входящих связей;
   - логарифмическое преобразование частот;
   - L2-нормализация строк;
   - TruncatedSVD для получения компактного представления.

Итоговая размерность: 74.

## Обучение

На Train обучаются:
- StandardScaler для поведенческих признаков;
- TruncatedSVD для графовых признаков;
- StandardScaler для спектральных признаков.

На последующих временных окнах используются те же преобразования
и фиксированный порядок хостов.

Модель не использует метки из тестовых окон для обучения эмбеддингов.

## Параметры

- role_dim: 64
- behavior_weight: 2.0
- role_weight: 2.0
- seed: 42

Параметры записаны в params.json.

## Предварительная проверка

Модель проверена на LANL 2017 Day 02.

Test:
- Pairs ROC-AUC: 0.9449
- Triplet accuracy: 0.9561
- New partners MRR: 0.1632
- Learned future links ROC-AUC: 0.9834

Learned future links использует отдельную логистическую регрессию,
обученную на Validation.

Эти результаты не являются результатами основного многодневного scoreboard.

## Ограничения

- Графовые координаты привязаны к обучающей когорте хостов.
- Модель не использует временную последовательность отдельных событий.
- Качество переноса между разными днями требует отдельной проверки.
- Косинусное сходство не всегда хорошо предсказывает будущие связи.
