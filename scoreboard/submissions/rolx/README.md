# rolx

## Кратко

RolX (Henderson et al., 2012): структурные роли — хаб, лист, мост — по форме окрестности, а не по собеседникам.

## Архитектура

Рекурсивные структурные признаки ReFeX (степень, сила, рёбра эго-сети, суммы и средние по соседям, 3 раунда) → неотрицательное разложение (NMF), 16 ролей. Вектор — доли принадлежности ролям.

## Данные

Граф строится из потоков окна (`src`, `dst`, число потоков). Каждое окно обучается заново, поэтому координаты окон разные: для узнаваемости окна выравниваются поворотом (Procrustes) по половине хостов.

## Обучение и подбор

Обучения с подбором нет: NMF на каждое окно, число ролей = 16.

## Ограничения

Отвечает на другой вопрос — «какая форма окрестности», а эталоны поощряют общих собеседников и похожее поведение, поэтому балл низкий. Это ожидаемо.
