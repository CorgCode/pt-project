# rolx

## Кратко

RolX (2012): ищет *роль* хоста в сети — хаб, лист, мост — по форме его окрестности, а не по тому, с кем именно он общается.

## Архитектура

Для каждого хоста считаются признаки окрестности: степень, сумма весов, число рёбер среди соседей, а затем те же величины, усреднённые по соседям (3 раза). Разложение на неотрицательные части (NMF) выделяет 16 «ролей»; вектор — насколько хост похож на каждую роль.

## Данные

Поля `src`, `dst` и число потоков. Граф строится заново по каждому окну, поэтому у каждого окна свои оси координат. Чтобы проверить узнаваемость (Identity), оси test-окна поворачивают к осям train по половине хостов (выравнивание Прокруста), а проверяют на другой половине.

## Обучение и подбор

Подбора нет: 16 ролей, одно разложение на окно.

## Ограничения

Отвечает на другой вопрос: два одинаковых сервера в разных отделах для него похожи, а эталоны поощряют общих собеседников. Поэтому балл низкий — это ожидаемо.
