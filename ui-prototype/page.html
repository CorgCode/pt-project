01 / ЗАДАЧА

Тысячи устройств.
Как понять, кто на кого похож?

У компьютеров есть привычки: обращаться к одним сервисам, общаться с определёнными узлами, быть активными в похожее время. Эти привычки становятся основой профиля хоста.

Наша цель — сервис для оператора SOC: находить похожие хосты, исследовать группы и замечать необычные переходы между ними.
