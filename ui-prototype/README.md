# PT NETWORK / 05

Непрерывная презентация проекта для посетителя без знаний ML: задача, карта сервиса, четыре шага модели, архитектура, протокол эксперимента, результаты и пошаговая демонстрация.

## Открыть

Откройте `index.html` в браузере. В него встроены шрифты, Three.js, стили, код и тестовые данные. Сетевые запросы для работы не нужны. WebGL нужен для объёмной сцены; при его отсутствии остаются текст, оформление и рабочая демонстрация.

Верхняя кнопка включает оригинальный спокойный ambient, синтезируемый Web Audio. По умолчанию звук выключен. Уменьшенное движение учитывается через `prefers-reduced-motion`.

## Исходники

- `page.html` — содержание и доступная HTML-структура.
- `style.css` — токены, стеклянные поверхности, типографика и адаптивность.
- `app.js` — сцена, управляемая прокруткой, демонстрация и аудио.
- `fonts/`, `fonts.css`, `oswald.css` — локальные Onest и Oswald, OFL.
- `data.js` — 300 behavioral-векторов из `app/testdata/synthetic_run`.
- `vendor/three.min.js` — Three.js 0.160.0, MIT.
- `build.py` — сборка самостоятельного HTML.

После правок: `python3 ui-prototype/build.py` из корня репозитория.

## Достоверность содержания

Архитектура и результаты взяты из карточек `multiday_codebook`, `multiday_codebook_plus` и таблицы среза `d0a336c` от 4 ноября 2026 года. Демонстрация сравнивает тестовые behavioral-векторы; она не запускает многодневную модель. Поддержка нового хоста, объяснения соседства, кластеризация и аномалии переходов остаются задачами сервиса.

## Визуальный ориентир

Изучен https://labs.noomoagency.com: светлый фон, узкий крупный Druk, прозрачная 3D-сцена и прокрутка как управление рассказом. Здесь применены собственные сетевые формы и кириллические шрифты Oswald / Onest. Оригинальные модели и материалы референса не использовались.

## Проверки

Проверены синтаксис JavaScript, сборка, автономность ресурсов, переходы демонстрации, точный расчёт ближайшего соседа, расширенный поиск, пустой результат, включение/выключение звука и отсутствие autoplay. Полный визуальный тест на 320 / 375 / 414 / 768 px и WebGL в браузере остаётся невыполненным: доступные инструменты браузера в этой сессии не запускаются.
