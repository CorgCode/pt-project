# PT / 05 — презентация проекта и демонстрация

Откройте `index.html` в браузере. Это самостоятельный HTML со встроенными стилями, библиотекой Three.js, данными и кодом. Сеть для открытия не нужна.

Исходники: `page.html`, `style.css`, `app.js`, `data.js`, `vendor/three.min.js`. После изменения запустите `python3 ui-prototype/build.py` из корня проекта.

Страница объясняет задачу, показывает переключаемые этапы модели, её архитектуру и результаты эксперимента из среза Git `d0a336c` от 4 ноября 2026 года. Данные презентации взяты из карточек `multiday_codebook` и `multiday_codebook_plus`.

Поиск использует 300 векторов behavioral из `app/testdata/synthetic_run`. Косинусное сходство рассчитывается в браузере. Демо не запускает multiday-модель и не показывает реальные сетевые соединения. Кластеризация, объяснения соседства и аномалии переходов остаются следующими этапами сервиса.

Three.js 0.160.0 (MIT): https://threejs.org/.
