# Host Explorer — прототип UI

Откройте `index.html` в браузере. Зависимости и сервер не нужны.

Прототип использует 300 синтетических эмбеддингов `behavioral` из `app/testdata/synthetic_run`. Поиск соседей вычисляет косинусное сходство непосредственно в браузере. Это демонстрационные данные, а не результаты модели multiday и не данные реальной сети.

Дальше: подключить API поиска хостов и группировки, когда инфраструктурная часть будет готова.
