# Состояние PT-05

Актуальные числа находятся в
[scoreboard/README.md](scoreboard/README.md); ниже описана доступность компонентов.

| Компонент | Что доступно в main | Ограничение |
|---|---|---|
| Подготовка данных | LANL → окна → когорта → эталоны | Сырые потоки скачиваются отдельно |
| Оценка | Метрики, score, интервалы и JSON-отчёты | Эталоны — приближения, не разметка ролей |
| Бейзлайны и графовые методы | Код, тесты и общий запуск | Требуются зависимости и данные прогона |
| Нейросетевые методы | Часть реализаций и адаптеров scoreboard | Нужен отдельно установленный PyTorch |
| Таблица LANL | Сохранённые результаты на днях 14–16 | История обучения у методов разная |
| Лидирующие codebook-модели | Карточки, параметры, метрики; SHA основы подтверждён локально | Полный публичный пакет обучения/inference отсутствует |
| Streamlit | Просмотр сохранённых результатов | Не исполняет модель как сервис |
| Сайт, лаборатория, рабочее место SOC | Сайт и лаборатория в `noomo-ui/`, локальное рабочее место в `app/operator/` | Для подключения полноценного инференса нужна модель |
| hostquery | Пакет поиска похожих хостов, группировки и локального API | Требуется набор с эмбеддингами |
| Роли и аномалии | Исследовательские задачи | Полезность для SOC не подтверждена |

## Воспроизводимость

В чистом checkout можно запустить тесты и конвейер на синтетике.
Для LANL требуются локальные потоки; для опубликованных нейросетевых моделей —
также исходники, конфигурации и checkpoints.
Ограничения — [docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md).

## Следующие законченные результаты

1. Опубликовать полный пакет выбранной модели: код, конфигурацию, окружение и способ получения весов.
2. Проверить повторный inference в чистом окружении.
3. Соединить модель с интерфейсом на полном целевом наборе устройств.
4. Проверить новые хосты и ранее не использованный период.
5. Измерить полезность для оператора: ложные сигналы, объяснения и время разбора.
