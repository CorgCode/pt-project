# PT-05 — стадия проекта и кто что сделал

Составлено по истории git (76 коммитов в main на момент составления), GitHub issues и pull request. Различаются два вида фактов: **назначено** (исполнитель issue) и **подтверждено кодом** (автор коммитов / PR). Назначение само по себе вкладом не считается. Оценок «в процентах» нет.

## Стадия проекта

**Исследовательская стадия (Research).** Построен общий конвейер и оценщик, реализованы 2 базовые модели и 5 графовых методов; всё проверено на синтетических данных. **Реального эксперимента на LANL ещё не было** (issue #60), поэтому научных выводов о качестве методов пока нет.

| Блок | Статус |
|---|---|
| Конвейер LANL → окна → графы → эталоны (`pipeline/`) | В main, проверен на синтетике |
| Единый оценщик (соседи, связи, пары, триплеты, P@k/R@k, идентичность) (`evaluation/`) | В main, проверен на синтетике |
| Базовые модели: поведенческая (+PCA/SVD), спектральный граф | В main |
| Графовые методы: DeepWalk, node2vec, RolX, struc2vec, GraphSAGE (`benchmark/methods/`) | В main, модульные тесты; результатов по ним нет |
| Беспортовая базовая модель (#43) | В main (PR #62, влит без ревью) |
| Устойчивость идентичности во времени (#41) | В main (PR #64, влит без ревью) |
| Прогноз связей, 3 метрики (#40) | В main (PR #65, влит без ревью) |
| Сайт для демонстрации | PR #66 |
| Линейный зонд (#25), кластеризация/аномалии (#21) | Не завершены |
| Независимый эталон сходства (#45) | Открыт |
| Реальный эксперимент на LANL (#60) | Не начат, нужен доступ к данным |
