# Результаты прогонов

Итоги прогонов на настоящих данных. Сами данные и эмбеддинги здесь не хранятся — только числа.

| папка | что | как получено |
|---|---|---|
| [`lanl_day02/`](lanl_day02/run/scoreboard_test.md) | первый прогон: LANL, день 02, все методы | [`experiments/lanl/`](../experiments/lanl/README.md) |

Внутри каждой папки:

- `run/scoreboard_test.md` — таблица результатов;
- `run/report.md` — отчёт с графиками и проверками;
- `run/results/` — все метрики по методам (JSON);
- `run/audit.json` — проверки валидности.

Открыть в дашборде: `streamlit run app/streamlit_app.py` — прогоны отсюда находятся сами.
Общая таблица команды, куда добавляются новые методы, — [`scoreboard/`](../scoreboard/README.md).
