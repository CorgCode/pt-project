## Что реализовано

Собственная реализация спецификации `experiments/dc_sage/Instruction.md`: directed GraphSAGE, два слоя по 128 скрытых координат, отдельные входящие/исходящие сообщения, IDF соседей, top64, остаточные связи, skip-MLP и нулевая инициализация графового выхода. 95 входных признаков = 64 TF-IDF/SVD координаты сервисов с ролями + 31 поведенческий признак; выход 64.

Сеть обучена InfoNCE по двум половинам train и асимметричным декодером связей S1→S2. Новые позитивные рёбра составляют половину обучающего набора. Негативы не содержат self-связей и настоящих рёбер S2. Есть dropout, AdamW/cosine schedule, gradient clip, контроль коллапса и величины графовой ветви.

Вопреки утверждению спецификации, skip-связь не гарантирует нижнюю границу качества: нулевая графовая ветвь гарантирует только начальное равенство выхода MLP. После совместного обучения качество может стать хуже, что и проверяют сравнения.

## Данные и выбор параметров

Из локального широкого train восстановлены текущие окна общей оценки: train `[126000,129600)` (9 368 480 потоков), validation `[129600,131400)` (4 526 585), test `[131400,135000)` (10 297 984). Test сейчас длится час, а не 30 минут из исторического примера инструкции. Когорта — 6453; оценка test — 5445. Порог и списки хостов взяты из текущего `scoreboard/data`, не из текста примера.

Числа потоков и события каждого хоста по каждому окну точно совпали с общим processed-манифестом. Потоки, пересекающие границы, исключены. S1 содержит 3 998 806 потоков, S2 — 5 144 117. 6264 хоста достаточно активны в обоих срезах для InfoNCE; граф содержит 26 437 узлов. Профиль хранит 49 057 токенов, включая обезличенные категории; min_df=2.

Все обучаемые преобразования подогнаны только на полном train. Локальные признаки S1/S2 считают только свои потоки. Рассмотрены три веса link loss (0.1, 0.3, 1.0), выбран 1.0 по официальному validation score на seed0. Остальные параметры — стартовые из инструкции. По validation выбиралась эпоха 25 или 50. Затем обучены 9 вариантов × 5 сидов. Все checkpoints зафиксированы до первого расчёта метрик test. Ни одна настройка не исправлялась ради улучшения увиденного test.

Одна эпоха здесь — один полнографный шаг с усреднением всех контрастных батчей по 512. Всего 50 обновлений AdamW; это не эквивалент 50 эпохам mini-batch SGD с отдельным обновлением после каждого батча. Пять сидов меняют инициализацию сети, dropout, батчи и выборку рёбер; SVD фиксирован seed0.

## Критерии успеха из инструкции

- `1_no_task_with_disjoint_adverse_seed_CI`: **False**.
- `2_future_or_shared_task_has_disjoint_favorable_seed_CI`: **False**.
- `3_neighbors_drop_at_most_0.02`: **True**.
- `4_score_at_least_linear`: **False**.

Критерий 1: нет задачи с непересекающимся неблагоприятным 95% интервалом сидов. Критерий 2: у Future links или Shared partners благоприятные интервалы не пересекаются. Критерий 3: падение Neighbors относительно skip-only не более 0.02. Критерий 4: средний общий балл не ниже линейного агрегата. Это предложенные автором эвристики, не доказательство эквивалентности при пересечении интервалов. Подробно: [success_criteria.json](success_criteria.json).

## Искусственные изменения

Для одних и тех же 272 хостов (5% test, seed2026) созданы независимые сценарии. Замена поведения удаляет их исходные потоки и копирует потоки случайного донора из другого KMeans-кластера замороженных train-векторов. Сканер добавляет каждому 200 попыток на порт 445 к случайным узлам. Безобидный сценарий дублирует все их потоки один раз. Параметры по результатам инъекций не подбирались.

| сценарий | ROC-AUC дрейфа DC-SAGE, 5 сидов | дрейф исходных признаков |
|---|---|---|
| role_change | 0.874 ± 0.013 | 0.921 |
| scanner | 0.791 ± 0.014 | 0.628 |
| benign_x2 | 0.486 ± 0.003 | 0.485 |

Дрейф — `1 − cos(train, изменённый test)`. Для двух первых сценариев желателен большой AUC; для безобидного изменения — около 0.5. Это диагностика реакции на синтетику, не оценка реальных атак. [Полные результаты](anomalies.json).
