# Быстрый временной графовый энкодер: LANL day02

| Модель | Исторический test 12:30–13:00 | Новый holdout 15:00–15:30 | Размерность |
|---|---:|---:|---:|
| hybrid_tfidf | 45.33 | 44.10 | 313 |
| v5: временной графовый энкодер | 46.85 | 45.90 | 825 |
| **v6 fast: v5 + PCA** | **47.57** | **46.49** | **384** |

Сравнивать методы нужно внутри каждого столбца. Когорта train — 6,453 хоста; в позднем окне оцениваются 2,462. Отбор конфигураций — только по validation. Позднее окно объявлено до выбора v6; после его оценки перенастройки не было. Train и validation при подготовке holdout побайтно совпали с исходными файлами ([проверка](holdout_day02_1500/training_data_check.json)).

Варианты с адаптивными весами были проверены, но не выбраны. Итоговая v6 использует обученный v5 и PCA 825→384, сохраняющий 99.77% дисперсии train. Поиск шести вариантов и оценка исторического test заняли около четырёх минут. Обработка архива для нового holdout и оценка — около шестнадцати минут. Время 1.23 секунды относится только к применению адаптера к уже вычисленным векторам, включая его загрузку.

Это результаты одного дня LANL. Исторический test уже использовался для анализа в предыдущих экспериментах. Поздний holdout проверяет перенос во времени внутри дня; перенос на другие дни ещё не проверен. Улучшение итогового score не означает улучшение каждой метрики или установленную статистическую значимость общей разницы.

В git сохранены небольшие JSON-результаты, протоколы и отчёты. Исходный трафик, эмбеддинги кандидатов и бинарные веса остаются в локальных рабочих папках и восстанавливаются запуском эксперимента.
