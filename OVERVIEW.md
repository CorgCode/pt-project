# Behavioral Denoising Autoencoder baseline

Новый нейросетевой baseline для CorgCode/pt-project: MLP denoising autoencoder поверх существующего поведенческого профиля.

Полные инструкции по добавлению в клон проекта и запуску — в [`INSTALL_RU.md`](INSTALL_RU.md).

Файлы расположены по тем же относительным путям, которые используются в репозитории. Настоящий LANL score не включён, так как запуск требует доступных тебе LANL-данных.
