# Исследование проблемы и решений

## Резюме подходов к пострению embedding и кластеризации

### Представление данных

**1. Агрегирование признаков хоста**

Агрегировать сетевые и host-события в профиль хоста за временное окно.

***

**2. Последовательности событий**

Формировать временную последовательность (сетевых + хостовых) событий.

Применимые методы:

- Word2Vec-подобные модели
- RNN/LSTM/GRU
- Transformer

***

**3. Гомогенный граф (хостов)**

например:
- вершины - хосты
- ребра (наличие + атрибуты) - сетевые взаимодействия

***

**4. Гетерогенные графы и гиперграфы**

- Разные типы объектов и связей
    - например, двудольные графы (связь вершин хостов через вершины портов / протоколов)

- Гиперграфы


***

**Временной граф**

Разные графы для разных временных окон. Для большого объема данных и для анализа переходов между кластерами (изменения поведенческого профиля).

***

### Построение embedding

**GNN: GCN, GraphSAGE, GAT**

Построение embedding хоста по его признакам, соседям и взаимодействиям.

- GCN
- GraphSAGE - применим к большим графам
- GAT - выделять более важные (частые / интенсивные / объемные) связи между хостами через т.н. attention

**Edge-aware GNN**

GNN с учетом признаков ребер: протокол, порт, объем и тд.

**Heterogeneous GNN**

GNN с разными типами вершин и связей.
Потенциально позволяет привязать Host Events к Network Events.

**Graph Autoencoder**

GNN с восстановлением связей графа и свойств.

**DeepWalk / node2vec**

Проще, но ограничение на учитывание доп. признаков из Host Events.


***

## Подходы к решению схожих задач (примеры)

### 1. Graph embedding для разделения серверов и клиентов

Xiao et al., "Towards Network Anomaly Detection Using Graph Embedding", ICCS 2020. [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC7303711/)

**Датасеты:**

- CIDDS-001;
- CICIDS-2017.
(наборы сетевого трафика с атаками)

**Исходные данные:**

Flow-записи сетевого трафика. В проверочной выборке были известны 7 серверов и 19 клиентов. [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC7303711/)

**Методы:**

Построение: 
- двудольный граф `IP - Port`;
- гиперграф потока вида `SrcIP - SrcPort - DstIP - DstPort`.

Методы:
- графовый embedding IP-адресов;
- DBSCAN для кластеризации;
- Random Forest для классификации потоков в эксперименте по IDS.

**Результаты:**

Хорошие метрики.
Модель смогла сгруппировать IP-адреса по их ролям в сети без разметки.

***

### 2. GNN-автоэнкодер для NetFlow anomaly detection

NVIDIA, "Applying Autoencoder-Based GNNs for High-Throughput Network Anomaly Detection in NetFlow Data, 2025". Индустриальная публикация. [developer.nvidia](https://developer.nvidia.com/blog/applying-autoencoder-based-gnns-for-high-throughput-network-anomaly-detection-in-netflow-data/)

**Датасеты:**

- NF-UNSW-NB15;
- NF-CICIDS-2018;
- NF-ToN-IoT;
- NF-BoT-IoT.

**Исходные данные:**

flow-записи сетевого трафика.

**Методы:**

Построение: 
Ориентированный граф flow-записей:

- IP-адреса - вершины
- сетевые потоки - направленные ребра с атрибутами

Методы:
- GAE (graph autoencoder): вершины - IP, ребра - flows. В ребрах атрибуты: время, объем, длительность
- GNN-encoder строит embedding вершин
- decoder оценивает вероятность существования взаимодействия
- связи с низкой вероятностью интерпретируются как аномальные

**Результаты:**

Отличные метрики - 98% верно найденных аномалий.
GAE позволяет обучаться на структуре графа без явной разметки ролей.
Подходит для выявления аномалий. Неясно насчет кластеризации по ролям.

### 3. MINOS: unsupervised NetFlow-анализ

MINOS, "Unsupervised Netflow-Based Detection of Infected and Malicious Hosts" — Boise State University. [scholarworks.boisestate](https://scholarworks.boisestate.edu/td/1601/)

**Датасет:**

реальный NetFlow-трафик академической сети за год. [scholarworks.boisestate](https://scholarworks.boisestate.edu/td/1601/)

**Исходные данные:**

NetFlow-записи без обязательной ручной разметки.

**Методы:**

- unsupervised host profiling
- GMM
- LSTM-Autoencoders
- построение модели нормального поведения по неразмеченным NetFlow-данным
- оценка отклонения поведения каждого хоста от нормального профиля
- ранжирование хостов по степени подозрительности.

**Результаты:**

Эффективность метода даже при анализе двух недель данных. [scholarworks.boisestate](https://scholarworks.boisestate.edu/td/1601/)
Подходит для выявления аномалий. Неясно насчет кластеризации по ролям.

## Анализ работы с датасетами

- Использование временных окон для большого объема данных

### 1. Flow-датасеты

(CIDDS-001, CICIDS-2017, UNSW-NB15, NF-CICIDS-2018, NF-ToN-IoT и др.)

Типовая обработка:

- исходные записи как отдельные потоки
- агрегация данных по хостам и временным окнам
- построение графа хостов с атрибутами ребер / гиперграфа потоков
- построение embedding

***

Xiao et al. преобразовали flow в графы `IP–Port` и гиперграфы, затем кластеризовали IP embedding алгоритмом DBSCAN. [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC7303711/)

В NVIDIA-подходе flow обрабатывались пакетами; IP превращались в вершины, а потоковые записи — в направленные ребра с атрибутами. [developer.nvidia](https://developer.nvidia.com/blog/applying-autoencoder-based-gnns-for-high-throughput-network-anomaly-detection-in-netflow-data/)

### 2. Датасеты логов событий на хосте

Типовая обработка:

- агрегация событий по хостам и временным периодам
- формирование профилей хостов за временной промежуток по событиям
- построение графа
- построение embedding
