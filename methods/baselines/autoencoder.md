# Behavioral Denoising Autoencoder (`behavioral_dae`)

## Идея

Нейросеть получает числовой профиль поведения хоста и учится восстанавливать исходный профиль по слегка зашумлённой копии. Узкий скрытый слой — 16 чисел — становится эмбеддингом хоста. Методу не нужны классы или ручная разметка.

## Признаки

Используется существующий `BehavioralBaseline`: объёмы потоков/байтов/пакетов, число собеседников, направления трафика, распределение по портам и протоколам, активность по часам. Поэтому входной вектор строится одинаково, а новая часть — обучаемая нелинейная нейросеть.

## Сеть и обучение

MLP автоэнкодер `n_features → 64 → 16 → 64 → n_features`; функция потерь — среднеквадратичная ошибка реконструкции (MSE), оптимизатор AdamW. Во время обучения к входу добавляется Gaussian noise (`noise_std=0.10`), но целевой вектор остаётся чистым — это denoising autoencoder. Начальные параметры и порядок мини-батчей фиксируются seed=17.

Обучение читает только train-окно. Для validation и test используется тот же обученный encoder, без дообучения; координаты общие. Стартовые параметры: 30 эпох, batch size 256, bottleneck 16. Менять параметры следует только после сравнения на validation, не по test.

## Ограничения

1. Это реконструкционный, а не контрастивный метод: он не обучен специально узнавать тот же хост в другое время.
2. Так как признаки совпадают с поведенческим бейзлайном, сильные метрики похожести поведения не доказывают независимого обнаружения роли или аномалий.
3. Требуется PyTorch (`pip install torch`); на этом этапе код и протокол подготовлены, но новый метод ещё нужно прогнать на настоящих данных LANL и сравнить с остальными на тех же окнах.
