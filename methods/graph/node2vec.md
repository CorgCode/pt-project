# node2vec

Grover & Leskovec, *node2vec: Scalable Feature Learning for Networks*, KDD 2016. Код: `node2vec.py`.

Блуждания второго порядка (параметр возврата `p`, параметр «вглубь/вширь» `q`; точный выбор — в `walks.py`) →
skip-gram с negative sampling, как в эталонной реализации. `p = q = 1` бит в бит совпадает с DeepWalk
с negative sampling (есть тест). Вес шага к вершине на расстоянии 2 от предыдущей — `1/q`: малый `q` уводит
блуждание от предыдущей вершины вглубь (как DFS), и векторы лучше передают сообщество; большой `q` держит его
рядом с ней (как BFS) — локальная структура. Малый `p` чаще возвращает назад. На графах с заданными сообществами разрыв косинуса «внутри минус между» монотонен по `q`
(0.44 при q = 0.25, 0.41 при q = 1, 0.36 при q = 4, по 8 графам).

`p` и `q` подбираем только на validation:

```bash
python -m experiments.tune_methods --processed-dir data/processed --reference-dir data/reference \
    --method node2vec --grid '{"p": [0.25, 1, 4], "q": [0.25, 1, 4]}' --metric pair_roc_auc
```

Стоимость как у DeepWalk (основное время — skip-gram, ≈200 тыс. пар/с); блуждания с перекосом генерируются
примерно в 5 раз медленнее обычных, но это всё равно мелочь (0.5 с на 25 000 блужданий длины 40).
