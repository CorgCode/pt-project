# Оценка эмбеддингов

Одна команда считает все метрики для эмбеддинга. Для команды есть короче —
[`scoreboard/`](../scoreboard/README.md): положил файл, получил место в таблице.

## Запуск

```bash
python -m evaluation.validate my/embeddings.csv                       # проверить формат
python -m evaluation.evaluate --embeddings my/embeddings.csv \
    --reference-dir data/reference/test --method my --output results/my.json
python -m evaluation.scoreboard --results-dir results --output results/scoreboard
```

## Формат эмбеддинга

```csv
host_id,emb_0,emb_1,emb_2
Comp001,0.12,-0.31,0.04
```

- `host_id` — строка, без повторов (`001` и `1` — разные хосты).
- `emb_*` — числа. Размерность любая.
- Нужны все хосты из `eval_hosts.csv`. Учиться можно только на train.

## Метрики

| колонка в таблице | вопрос | случайный уровень |
|---|---|---|
| Соседи@10 | ближайшие соседи хоста те же, что по поведению в логах? | ≈ 10 / число хостов |
| Связь, AUC | по близости видно, кто с кем будет общаться? | 0.5 |
| Новые собеседники, MRR | похожие хосты подсказывают новых собеседников? | лучший прогноз без эмбеддинга |
| Пары, AUC | хосты с общими собеседниками ближе, чем без них? | 0.5 |
| Тройки | хост ближе к похожему, чем к непохожему? | 0.5 |
| Узнаваемость, Top-1 | тот же хост через время находится первым? | 1 / число хостов |
| Зонд, accuracy | внешнее свойство хоста читается из вектора? (нужны настоящие метки) | доля частого класса |

Ещё есть устойчивость к удалению связей: `python -m experiments.robustness`.

Эталоны строит `python -m pipeline.reference` по более позднему окну, без участия эмбеддингов.
Нет файла эталона — метрика помечается «недоступна».

## Как добавить метрику

1. Функция в `evaluation/<имя>.py`.
2. Если нужен новый файл эталона — построить его в `pipeline/reference.py`, только из логов.
3. Одна строка в `METRICS` в `evaluation/evaluate.py`:

   ```python
   Metric("my_metric", "Группа", "Название", ("my_reference.csv",), _my_metric, "my_number", lambda r: 0.5)
   ```

4. Тест `evaluation/test_<имя>.py`. Метрика сама попадёт в отчёт и таблицу.

## Важно

- Эталоны — приближение похожести, а не правда о ролях. Про роли говорит только зонд с настоящими метками.
- Числа с разных эталонов не сравниваются — таблица этого не даст.
- Синтетика проверяет код, а не методы.

Подробности и проверки валидности — [`docs/METHODOLOGY.md`](../docs/METHODOLOGY.md).
