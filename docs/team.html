Команда и сроки

Кто какие задачи взял, что сдал и успел ли к сроку. Данные подтягиваются с GitHub при открытии страницы: задачи (issues), сроки (milestones) и влитые PR. Проект — LANL, эмбеддинги хостов.

Участники

«Сдано» — задача закрыта как выполненная. PR — влитые в main и ещё открытые, где участник автор.

Сроки

Срок — это milestone с датой. Время можно уточнить строкой «срок: ГГГГ-ММ-ДД ЧЧ:ММ» (по Москве) в его описании, иначе срок — конец указанного дня. Задача без milestone срока не имеет. Время сдачи — когда задачу закрыл сам исполнитель; если закрыл другой — последний комментарий исполнителя до закрытия.
