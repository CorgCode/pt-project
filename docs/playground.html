Вспомогательный инструмент

Проверка собственного файла эмбеддингов

Загрузите embeddings.csv и посмотрите, насколько ближайшие соседи ваших векторов совпадают с учебным эталоном. Файл обрабатывается в вашем браузере и никуда не отправляется.

Это учебный пример. Эталон — синтетический набор из 300 хостов (h0 … h299), а не реальные данные LANL. Результат не заменяет полный отчёт исследования.

Как пользоваться

  1. Нажмите «Скачать пример CSV», чтобы увидеть формат: столбец host_id (значения h0 … h299) и столбцы emb_0 … emb_d.
  2. Выберите свой файл и нажмите «Оценить эмбеддинги».
  3. Сравните строку «Загруженный CSV» с двумя ориентирами: случайными векторами и эталонным максимумом (модель с утечкой).

Ограничения

Здесь считаются только согласие соседей (Consistency), Jaccard и nDCG для k = 5, 10, 20 по косинусной близости. Остальные метрики — парный ROC-AUC, точность триплетов, прогноз связей, линейный зонд — доступны в основном Python-оценщике при наличии эталонов (METRICS.md).
