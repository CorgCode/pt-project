# Воспроизводимость и артефакты

## Что повторяется из чистого checkout

Тесты и `python -m experiments.end_to_end --fixture --workdir runs/demo` используют
сгенерированные данные. Streamlit может открыть закоммиченный синтетический пример.
Публикация реальных результатов не означает наличия всех весов в репозитории.

| Набор | Есть в Git | Что нужно дополнительно |
|---|---|---|
| Синтетический пример | Генератор, тесты, небольшой прогон | Python-зависимости |
| Общие эталоны LANL 14–16 | CSV, манифесты, хеши | Для пересборки — исходные потоки |
| Доступные методы | Код и карточки | Подготовленные данные, иногда torch |
| Результаты scoreboard | JSON, CSV, Markdown | Исходные векторы для независимого пересчёта |
| multiday_codebook | Карточка, параметры, SHA checkpoint и метрики | Полный опубликованный код и доступ к checkpoint |
| multiday_codebook_plus | Карточка, параметры, метрики | Основа, код дополнительной головы и сборки векторов, веса |

Checkpoint основы найден локально и проверен по SHA; инструкция — [ARTIFACTS.md](ARTIFACTS.md).
Наличие весов на диске не означает наличия полного пакета кода в Git.

## Окружение

CI настроен на Python 3.11 и 3.12. Локальные проверки уборки выполнены на Python 3.12.
`requirements.txt` ограничивает диапазоны версий, но не является полным lock-файлом.
Для конкретного прогона сохраняйте `python --version`, `python -m pip freeze`,
seed, конфигурацию, commit SHA, хеши данных и весов.
Создавайте отдельный venv; не переносите его между машинами.

## Данные и веса

Локальные каталоги: `data/`, `runs/`, `PT_PROJECT_ML/`.
Не добавляйте raw NetFlow, checkpoints, токены и личные пути в Git.
Карточка метода должна содержать:

1. Команды подготовки, обучения, выбора на development и inference.
2. Точные временные границы, когорту и поведение для новых хостов.
3. Способ получения исходных данных и разрешённых к передаче весов.
4. SHA-256 артефактов и сохранённое окружение.
5. Проверку повторного inference в новом процессе.

## Исторические служебные файлы macOS

В `scoreboard/data/reference/*/manifest.json` исторически попали хеши 28 файлов
`._*.csv` (AppleDouble). Они не являются входом метрик, но входят в опубликованные
манифесты. Пока сохраняем их вместе с исходными манифестами: изменение манифестов
делает старые fingerprints оценки неактуальными, а векторы всех методов недоступны.
Служебные файлы вне манифестов удалены; новые запрещены `.gitignore`.
Генератор новых эталонов не включает `._*` в контрольные суммы.

Удаление оставшихся файлов — отдельная миграция происхождения артефактов, не
основание переписывать опубликованные scores без пересчёта.
`python tools/check_repo.py` проверяет сохранённые файлы и их хеши.
