# Монитор обучения

Откройте `training-monitor.command` двойным щелчком в Finder или запустите
в Terminal из каталога проекта:

```bash
./training-monitor.command
```

По умолчанию показан самый свежий прогон: прогноз собеседников, быстрый подбор,
32 часа или8 часов.
Обновление каждые2 секунды. Для конкретного прогона используйте `--work`.
Монитор читает состояние и логи; обучение продолжает работать независимо от окна.

| Клавиша | Действие |
|---|---|
| `1` | Обзор: стадия, прогресс, CPU, RAM, swap |
| `2` | Дни и эпохи: обработанные строки, loss, состояние голов |
| `3` | Рейтинг validation и итоговый test, когда он готов |
| `4` | Последние строки логов текущей стадии |
| `Tab` | Следующая вкладка |
| `[` / `]` | Предыдущий / следующий лог |
| `↑` / `↓` | Прокрутка |
| `g` | Вернуться к началу вкладки / последним строкам лога |
| `r` | Обновить сразу |
| `Space` | Приостановить обновление монитора |
| `q` | Закрыть монитор |

Пауза и закрытие монитора не останавливают обучение.
Loss и номер эпохи записываются обучением раз в10 эпох.
ETA приблизительная и относится только к текущей голове.
Балл validation служит для подбора; итоговый балл test показывается отдельно.

Другой прогон или один текстовый снимок:

```bash
./training-monitor.command --work /Volumes/KINGSTON/PT_PROJECT_ML/fingerprint_memory
./training-monitor.command --once
./training-monitor.command --interval 5
```

Используется существующее окружение `.venv` с `psutil`; новых пакетов не требуется.
