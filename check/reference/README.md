# Canonical reference, version 1

Generated on 2026-10-05 by:

```bash
python3 build_reference.py --labels role_labels.csv --out-dir reference --seed 20261005
```

Source annotation: `../role_labels.csv`, generated by
`../label_hosts_by_ports.py` with its default dominance and distinct-client
thresholds. This is silver (heuristic) service-role annotation, not ground
truth from asset inventory.

Policy: 10 deterministically selected hosts per role (`dns_server`,
`domain_controller`, `file_server_smb`, `ssh_server`, `voip_server`,
`web_server`); five per role in each host-disjoint split. Same-role pairs are
labelled `1`, different-role pairs `0`. For every split there are 60 positives
and a deterministic sample of 300 unique negatives. Do not edit, regenerate,
or select a new pair subset per embedding method.

This reference measures separation of service-role behaviour. It is unsuitable
as an independent test for an embedding trained mainly on the same known-port
signals; for that case create a later version from a separate time interval or
asset-inventory labels.
